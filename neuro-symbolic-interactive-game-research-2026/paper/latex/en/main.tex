\begin{abstract}
Large language models can generate expressive quests and dialogue, but fluent or schema-valid text does not establish that a proposed event is executable, authorized, or consistent with canonical game state. We present \system, a symbolic commit gate that treats each generated event as an untrusted transaction proposal. A type-strict parser, an external action policy, and seven deterministic checks grouped into six state-relative families decide each transition; a failing candidate may enter bounded repair for at most $K+1$ recorded attempts, and a passing candidate is revalidated before mutation. The validator-error-guided operator $\rho$ reads only the prior candidate and typed validation errors; those errors are its sole state-derived input, and it never accesses authoritative \texttt{WorldState} directly. Unkeyed SHA-256 content links, state-semantic replay, and assignment-complete accounting make terminal outcomes auditable. Four evidence lanes stay separate: offline conformance over one authored world, single-model live screening, closed-world knowledge-graph link simulation without runtime authority, and a Godot engineering slice without participants. The offline lane establishes mechanism conformance only; at $K{=}1$, live screening observed 5/5 guided versus 0/5 blind commits solely in a deliberately repairable policy-blind regime, so it remains pilot-only. No lane establishes population efficacy, model superiority, player experience, or commercial-engine performance.
\end{abstract}

\section{Introduction}
\IEEEPARstart{I}{nteractive} generation is more than a language task. A candidate event may be natural yet require an absent item, assert a fact unknown to its speaker, reveal forbidden quest information, introduce an unauthorized effect, or regress a quest stage. Executable text environments make the distinction between a plausible utterance and a valid transition explicit \cite{S11_cote2019textworld,S12_wang2022scienceworld}. Grounded dialogue and personalized quest systems further show the value of quest, entity, and graph context \cite{S03_weir2024ontologically,S20_ashby2023personalized}, but context does not itself authorize canonical mutation. \textbf{\system{} treats generated game events as untrusted transaction proposals and permits canonical state mutation only through an external, deterministic commit gate.} Fig.~\ref{fig:architecture} reads one such transaction left to right.

Structural constraints solve an adjacent problem: grammar-constrained decoding, query languages, and incremental parsers restrict generated structures \cite{S09_geng2023grammar,S10_beurerkellner2023prompting,S36_scholak2021picard}, yet a syntactically admissible event can still be false relative to the current world. Retrieval and memory supply useful evidence \cite{S04_he2024gretriever,S05_gutierrez2024hipporag,S06_chhikara2025mem0}, but retrieved content is not a state-transition authority either.

This paper presents \system, an implementation that combines these concerns as an auditable transaction protocol. Its current contributions are:
\begin{enumerate}
  \item \textbf{C1---Contracts:} versioned trust-boundary contracts and a type-strict parser that rejects unknown keys and ambiguous types at proposal and replay boundaries (Sec.~\ref{sec:arch}; E1);
  \item \textbf{C2---Controller:} a validate--repair--commit controller with seven checks across six state-relative families, bounded repair, unchanged fallback, and pre-commit revalidation (Sec.~\ref{sec:repair}; E1, ENG1);
  \item \textbf{C3---Audit:} SHA-256-linked records, state-semantic replay, and episode-continuity checks (Sec.~\ref{sec:audit}; E1, ENG1);
  \item \textbf{C4---Harness:} an assignment-complete offline conformance harness that keeps a classified terminal row even when no proposal trace can exist (Sec.~\ref{sec:lanes}; E1); and
  \item \textbf{C5---Repair:} the typed validator-error-guided operator $\rho(a,E)$ (implemented as \texttt{counterexample\_guided\_repair}), compared with blind retry and a state-reading oracle across frozen repairability classes (Sec.~\ref{sec:repair}; E1, E2).
\end{enumerate}
The fixed-goal NPC operation is additive descriptive evidence under NPC-ENG1/NPC-SCR1, not C6 or a C-RESULT. For one game-owned Mira goal, Python emits typed intent and bounded public-projection plans; Godot alone writes canonical state. The 88-case one-step protocol screening is separate from a normal-play full-loop episode demonstration. Only player-request \texttt{acquire\_object}/\texttt{install\_lens} can cause physical action; Mira alone may commit authorized \texttt{tide\_marks\_hint}; \texttt{clarify}/\texttt{negotiate} are dialogue-only. P/R/O denote the authenticated Codex adapter, authored rule interpreter, and same-family auxiliary reference (zero independent rows). This is engineering/provenance evidence only; P/R/O apply only to NPC-SCR1, while ENG1 is hard conformance.

\section{Related Work and Research Gap}
\subsection{Interactive Narrative and Game Agents}
KNUDGE grounds branching NPC dialogue in quest and entity specifications \cite{S03_weir2024ontologically}; knowledge-graph quest generation \cite{S20_ashby2023personalized}, memory--reflection--planning agents \cite{S07_park2023generative}, and trainable role-playing agents \cite{S08_shao2023character} address complementary aspects of grounded, believable behavior. Player-facing studies evaluate preference and perceived dialogue quality \cite{S21_akoury2023player,S22_hochreiter2026beyond,S23_yin2026contextualized}, and a 2025 preprint reports role-sensitive stability--improvisation trade-offs \cite{S02_figueiredo2025scaffolded}; both motivate separating hard admissibility from optional naturalness and player-experience constructs.

Experience-driven generation, observer-labelled engagement, and limits of vision-language engagement inference motivate future affect work \cite{S24_yannakakis2011experiencedriven,S25_melhart2020engagement,S26_wang2026engagement}; affect is non-authoritative and absent here.

\subsection{Environments and Benchmarks}
TextWorld and ScienceWorld expose explicit interactive state \cite{S11_cote2019textworld,S12_wang2022scienceworld}, MineDojo adds open-ended embodied tasks \cite{S13_fan2022minedojo}, and GVGAI separates agent, game, and content tracks \cite{S14_perezliebana2019gvgai}. AgentBench, AgentBoard, SOTOPIA, and BALROG evaluate agents across heterogeneous, process-diagnosed, social, and long-horizon game settings \cite{S15_liu2024agentbench,S16_ma2024agentboard,S17_zhou2024sotopia,S18_paglieri2025balrog}; automated play-style agents complement rather than replace human evaluation \cite{S19_lepelletier2022playtesting}. Across these reviewed environments and benchmarks, we did not identify a single protocol that combines transactional authorization, typed repair, semantic replay, and assignment-complete accounting; this is a scope-limited review finding, not a first-ever claim.
NCP-Bench adds a long-horizon interactive-narrative benchmark for commitment and fact consistency, but it does not evaluate \system{} or player outcomes \cite{S58_ma2026ncpbench}.

\subsection{Constraints, Neuro-Symbolic Validation, and Retrieval}
Constrained decoders improve output structure \cite{S09_geng2023grammar,S10_beurerkellner2023prompting,S36_scholak2021picard}; \system{} instead treats structure as an input condition to independent state-relative authorization. The same generate-and-verify division is established outside games: LLM-Modulo frameworks let a model propose plans that external sound critics accept or reject \cite{S50_kambhampati2024llmmodulo}, and SayCan admits a language-proposed skill only after a state-dependent affordance check \cite{S51_ichter2023saycan}. AgentSpec expresses runtime rules for LLM agents as trigger--predicate--enforcement triples \cite{S52_wang2025agentspec}; \system{} fixes the predicates to game state and adds a repair contract and replayable records. Setting the DC grounds D\&D agents in tool calls with precondition checks \cite{S53_li2025settingdc}, whereas \system{} admits free-text proposals only after parsing and external policy evaluation. STORY2GAME lets the LLM generate the action preconditions and effects it plays under \cite{S54_zhou2025story2game}; here the policy is authored independently of the proposer. \system{} instantiates the critic as a deterministic, state-relative commit gate that returns typed counterexamples. Game-specific comparators span complementary boundaries: PANGeA validates content by asking an LLM to judge and refine it against designer rules \cite{S42_buongiorno2024pangea}; IVIE incrementally generates interactive-fiction worlds with symbolic validation \cite{S01_vaucher2026ivie}; and a 2026 successor restricts the LLM to selecting authored world-state transformations \cite{S44_gongora2026worldstate}, gaining consistency by construction while leaving this paper's transaction, audit-record, and repair-operator questions as separate evidence targets. No comparison implies superiority: validity is only validity for the predicates a system encodes.
JSONSchemaBench measures structural constrained-output compliance, coverage, and quality; those measures do not establish state-relative semantic authorization \cite{S57_geng2025jsonschemabench}.

G-Retriever, HippoRAG, and Mem0 address subgraph retrieval and long-term memory \cite{S04_he2024gretriever,S05_gutierrez2024hipporag,S06_chhikara2025mem0}; Generative Agents and Character-LLM address behavioral memory and persona \cite{S07_park2023generative,S08_shao2023character}. \system{} may consume such context but grants it no commit authority; benefits are unmeasured.

\subsection{Auditability and Reproducibility}
Process metrics, sparse-run caution, reproducibility, and environmental reporting motivate failure retention and frozen artifacts \cite{S16_ma2024agentboard,S31_agarwal2021precipice,S33_pineau2021reproducibility,S34_henderson2020energy}. Human/LLM evaluation and future participant analyses require construct/rater/bias controls, justified margins, and random-effects structures \cite{S27_vanderlee2019best,S28_karpinska2021perils,S29_zheng2023judging,S30_chen2024judgement,S32_lakens2018equivalence,S35_barr2013random}. Record-and-replay supports experience reuse \cite{S56_feng2025agentrr}; \system{} claims only semantic replay of admitted transitions.
Leakage checks protect frozen denominators but do not create efficacy evidence \cite{S59_sun2025bdc}.

The bounded novelty is the implemented combination, not its individual parts. Prior work covers runtime enforcement \cite{S52_wang2025agentspec}, symbolic game-state management \cite{S53_li2025settingdc,S54_zhou2025story2game}, feedback repair \cite{S45_madaan2023selfrefine}, record/replay \cite{S56_feng2025agentrr}, action interposition \cite{S37_riedl2003managing}, classical preconditions/effects \cite{S39_fikes1971strips}, permitted-transition enforcement \cite{S40_schneider2000enforceable}, transaction abort \cite{S49_haerder1983transaction}, authored social logic \cite{S38_evans2013versu}, and belief-aware narrative planning \cite{S41_ware2021sabre}. \system{} combines these at a game-state commit boundary: C1--C2 enforce independent contracts and validate--repair--commit; C3--C4 add checksum-linked/state-semantic replay, episode continuity, and assignment-complete accounting; C5 isolates typed-error repair. Absence from a report is not absence from an implementation.

\section{Problem Definition and Guarantee Boundary}
For exposition, the controller input used by validation at step $t$ is decomposed as $c_t=(G_t,q_t)$, where $G_t$ denotes typed snapshot fields and $q_t$ denotes the externally authored action-policy, disclosure, and quest-stage constraints stored with that snapshot. Terminal record history $h_{<t}$ is maintained separately from the \texttt{WorldState} snapshot; no validation predicate reads it, and the implementation does not reconstruct state from the log. In this one-step model, an accepted transition updates $G_t$ under $q_t$ and carries $q_t$ forward unchanged; policy-version rotation is outside the transition. Retrieval, narrative scores, model rationales, memory summaries, and any future affect estimate are non-authoritative proposal context.

An untrusted proposer emits candidate $a_t$. Strict parsing first enforces the shared candidate-key contract, including rejection of unknown top-level fields, and establishes the declared schema. The validator returns
\begin{equation}
V(c_t,a_t)=(v_{\mathrm{policy}},v_{\mathrm{pre}},v_{\mathrm{reach}},
v_{\mathrm{know}},v_{\mathrm{disc}},v_{\mathrm{elig}},v_{\mathrm{stage}},E_t),
\end{equation}
where $E_t$ is a structured error set. Mutation is
\begin{equation}
c_{t+1}=\begin{cases}
T(c_t,a_t), & \bigwedge_{i=1}^{7} v_i=1,\\
c_t, & \text{otherwise.}
\end{cases}
\label{eq:transition}
\end{equation}

The controller asserts the following implementation invariants under its encoded contracts; the pilot tests their mechanisms with deterministic valid, invalid, repair, fallback, replay, and fault-injection fixtures rather than presenting general theorems. \textbf{I1 (exhausted-failure immutability):} if no returned candidate through budget $K$ validates, or proposal/controller execution fails before commit, the returned state equals the supplied prior state. \textbf{I2 (bounded recorded attempts):} provided every proposal and repair callback returns, repair budget $K\geq0$ admits at most $K+1$ recorded candidate attempts; a successful commit adds one defensive validation immediately before mutation. The runtime does not enforce callback deadlines, so I2 is not a wall-clock termination guarantee. \textbf{I3 (effect authorization):} an accepted candidate contains no declared fact effect in \texttt{CandidateAction.effects} outside \texttt{ActionPolicy.allowed\_effects}, and any quest-stage target is explicitly authorized by that policy. \textbf{I4 (state-semantic replay):} with the frozen schemas and deterministic transitions, an accepted trace reconstructs its stated terminal state.

These invariants assume correct policy authorship, faithful extraction into declared candidate fields, deterministic software versions, returning callbacks, and single-process file ownership. Replay revalidates the recorded structured candidate and transition; it does \emph{not} verify the provenance, prompts, or stochastic generation of intermediate repairs, and natural-language implications omitted from structured fields remain outside the guarantee.

Validation errors are exposed to a repair callback as structured error codes. Repair never directly mutates state, and exhaustion returns an unchanged deterministic fallback. Fig.~\ref{fig:architecture} shows the terminal paths. The pilot compares two implemented callbacks. The \emph{typed validator-error-guided operator} (implemented as \texttt{counterexample\_guided\_repair}) reads only the prior candidate $a$ and typed validator errors $E$; these errors are its sole state-derived input, and it never accesses authoritative \texttt{WorldState} directly:
\begin{equation}
\rho(a,E)=a \oplus \textstyle\bigcup_{e\in E}\delta(e),
\label{eq:rho}
\end{equation}
where each $\delta(e)$ is the deterministic per-error-class edit of Table~\ref{tab:rho-rules} and $\oplus$ applies the resulting field edits. Each edit touches at most one candidate field per error entity, so the number of changed fields per attempt is bounded by $|E|$; applying $\rho$ twice with the same error set is a fixed point only for that identical $E$, not a convergence claim across changing error sets or attempts; and an entity simultaneously demanded and rejected on the same field is declared irreparable and left untouched. The \emph{state-reading reference callback} instead discards the error set and reconstructs the policy-governed fields (preconditions, effects, and both quest-stage fields) directly from the authoritative state; it deliberately never edits declaration-integrity fields (required objects, used facts, disclosed facts), because those are authored declarations rather than state-derived repairs.

\subsection{Integrity, Semantic Replay, and Accounting}\label{sec:audit}
Each result row carries an unkeyed SHA-256 \emph{integrity checksum}, and proposal outcomes link to a trace checksum; these detect accidental or tested content changes but are not signatures, writer identity, or protection against an actor who rewrites content and checksums. Semantic replay strictly parses the prior state and every recorded candidate/validation pair, requires every nonfinal attempt to be invalid, recomputes the terminal transition, compares the stated final state, and requires continuity between adjacent JSONL records; it does not re-execute the repair step that produced candidate $j+1$.

The terminal record classes are commit, symbolic fallback, adapter failure, and controller failure. A controller-failure row remains in the frozen assignment denominator and leaves state unchanged, but it may legitimately lack a completed proposal trace because no candidate outcome was produced. Accordingly, result completeness does not imply trace existence for every terminal row. The pre-execution assignment key contains run, arm, scenario, seed, model, revision, controller-configuration hash, assignment-input hash, and prior-state hash. Aggregation rejects duplicate, missing, or unexpected keys and separately reports symbolic, adapter, and controller failures.

\subsection{\textbf{E1} Offline Conformance Design}
The pilot asks whether (PQ1) valid candidates commit while named invalid-policy cases remain unchanged; (PQ2) rejection-only, blind unchanged retry, $\rho$, and the state-reading reference callback produce the expected outcome in every frozen repairability class; (PQ3) frozen checksum, state-semantic, linkage, and continuity mutations are rejected by their designated check operations and an injected second-file append failure triggers the pair-write rollback check; (PQ4) strict adapters and assignment manifests retain exactly one classified terminal row per assigned case or fail closed; and (PQ5) proposal and replay parsers both reject an otherwise-valid candidate carrying one unknown top-level key.

Cases are purposively designed conformance fixtures in four domains (validator/state isolation, repair-arm comparison, record/trace fault injection, adapter/accounting contracts), not samples from a model or game population. Every repair fixture declares a frozen repairability class before execution: \emph{guided-repairable} (the error payload alone suffices for $\rho$), \emph{oracle-only} (repair needs the authoritative state), or \emph{irreparable} (no arm may commit); the 13 gate fixtures comprise one valid control plus 12 isolated negatives, while the 12 repair cases form a separate arm denominator; each class's expected outcome per arm is part of the fixture contract, unique cases form the denominators, and all expectations precede execution.

Measures are exact counts: validator-class agreement; rejected or failed cases with state mutation; commit and attempt outcomes by arm and repairability class; detectable faults rejected by their designated operation; replayed traces; rejected manifest violations; and proposal/replay parity on the unknown-key regression, which is parser-contract parity rather than a safety outcome. Exception class alone does not identify a stable detector layer, so no detector attribution is reported, and no $p$-values or population intervals are attached. Adapter cases carry JSON-Schema-pinned synthetic latency and token constants that exercise accounting propagation only. The frozen offline packet binds fixtures, assignments, schemas, results with embedded traces, code revision, and checksums, following reproducibility and measurement-boundary guidance \cite{S33_pineau2021reproducibility,S34_henderson2020energy}.

\subsection{\textbf{E2} Live RQ2 Screening}
The live extension compares blind unchanged retry with $\rho$ at matched $K{=}1$: per cell, five seed-indexed calls to the hosted proposer \texttt{gpt-5.6-sol} request one candidate, and the same candidate feeds both arms, eliminating within-call proposal differences. Conditions vary policy visibility and whether a trivial zero-effect route exists. The frozen packet retains the current cells and the superseded v1 diagnostic, binds every receipt by SHA-256, and is labelled pilot-only. Because seed labels do not control the hosted sampler, the revision is unpinned, token accounting is unavailable, and constructed states are not population samples, we report exact counts and failure classes without $p$-values, confidence intervals, or model ranking.

\subsection{\textbf{NPC-ENG1} Fixed-goal engineering lane}
NPC-ENG1 is a deterministic native 16-case rule-control lane covering bootstrap, identity/hash binding, intent/plan/role/result transitions, negative gates, stale/duplicate/deadline paths, and replay. Stable v5 defines 16 engineering assignments and 12 screening recipes; earlier packets are immutable provenance. Historical preflight diagnostics remain outside NPC-SCR1 outcomes; final statuses, counts, and latencies come only from the validated packet. This lane is protocol/engine evidence only; reproduction uses \path{research/academic-pipeline/npc-goal-recovery/verified-run-001/} and the repository runner/validator.

\subsection{\textbf{NPC-SCR1} Descriptive screening}
NPC-SCR1 fixes 12 cases, two repetitions, and three arms (P/R/O): 72 rows, 24 per arm; with ENG1, 88 rows total ($R=40$, $P=24$, $O=24$). All assigned rows—including pre-trigger, parse, deadline/cancel, duplicate/stale, controller, and no-route—remain in the denominator; recovery-eligible and unreachable strata stay separate. P is the authenticated Codex OAuth adapter without fallback; R is authored rule/grammar control; O is a frozen same-family auxiliary from the same public input, not an independent oracle. The auxiliary-source fraction is 100\%, independent fraction zero. Screening is descriptive/provenance only—not recovery efficacy, semantic gold, accuracy ceiling, model ranking, or C6.
Generated results provide observed counts for the assigned P/R/O rows; the normal-play full-loop episode demonstration remains a separate artifact outside this one-step protocol pool.

\subsection{\textbf{E3} KG/Ontology Link-Proposal Simulation}
The third lane is an engineering-only closed-world simulation, separate from the authoritative \texttt{WorldState}: 43 graph nodes and 106 reference edges, 24 reviewed typed edges, passing type/domain/range checks and six competency questions, with six authored queries scored under seven fixed strategies. The retained typed-lexical strategy (S2) recovered 6/6 authored holdouts ($P=R=F_1=1.000$, realistic-tie $\mathrm{MRR}=0.944$, Brier $=0.131$, $\mathrm{Sem}@3=1.000$); the degree baseline recovered none. These are construction results: not OWL/SHACL conformance, semantic completeness, runtime retrieval, or evidence of any efficacy claim.

\section{Discussion}
\subsection{Established Scope}
The frozen pilot establishes mechanism behavior only: encoded checks isolate state, declared repair/fallback paths hold, named corruptions are rejected, and rows remain classified; no stable detector attribution is made.
NPC-ENG1 is synthetic closed-world evidence; NPC-SCR1 is one-step screening; the normal-play episode is separate and illustrative. Utterances/model output cannot change the fixed goal. Python emits typed intent/bounded public BFS; role gates route player/Mira reveal; replanning uses observations. P/R/O are adapter/control/auxiliary with zero independent rows; counts do not estimate efficacy, superiority, generalization, human benefit, cost equality, semantic gold, or accuracy ceilings.

Offline, state-reading handles oracle-only cases $\rho$ cannot; $\rho$ matches it on guided-repairable cases using typed errors. Live separation from blind retry occurred only in that regime; null already-valid/irreparable regimes, unpinned revision, and quasi-replicated calls preclude sample-efficiency/model-capability claims. Self-Refine, Reflexion, and Self-Debugging are precedents \cite{S45_madaan2023selfrefine,S48_shinn2023reflexion,S46_chen2023selfdebug}; $\rho$ instead consumes deterministic pre-execution errors, keeps failed arms isolated, and is not semantic repair, only analogous to counterexample-guided synthesis \cite{S47_solarlezama2006sketching}.

\subsection{Relationship to Prior Work}
\system{} complements constrained decoders \cite{S09_geng2023grammar,S10_beurerkellner2023prompting,S36_scholak2021picard}, retrieval/memory \cite{S04_he2024gretriever,S05_gutierrez2024hipporag,S06_chhikara2025mem0}, executable benchmarks \cite{S11_cote2019textworld,S12_wang2022scienceworld,S15_liu2024agentbench,S18_paglieri2025balrog}, and process-linked measurement \cite{S16_ma2024agentboard}; none demonstrates outperformance. Planned (not executed) studies are preregistered multi-model/oracle/blind-retry comparison, matched-validity retrieval/memory ablations, and a blinded matched-validity human study with justified power/mixed-effects; screening substitutes for none \cite{S27_vanderlee2019best,S31_agarwal2021precipice,S35_barr2013random}.

\section{Threats, Ethics, and Artifact Scope}
Nine boundaries apply: \textbf{L1:} encoded fields miss semantics; consistency is not behavior consistency \cite{S55_huang2026beyond}, and narrative quality is unmeasured. \textbf{L2:} one world/live state gives no cross-world, cross-policy, or scale generalization. \textbf{L3:} state-reading is an oracle; classes/regimes do not establish repair quality/sample efficiency. \textbf{L4:} one hosted proposer has unpinned revision, no token accounting, and uncontrolled seeds; E2 screening has no Python--Godot authorization round trip. \textbf{L5:} no participant/affect data or comprehension/agency/enjoyment/immersion/benefit evidence. \textbf{L6:} unkeyed hashes provide integrity, not authentication/tamper resistance. \textbf{L7:} one-writer consistency leaves concurrency unverified. \textbf{L8:} one Godot fixture has startup-dominated samples above 16.7\,ms; portability/performance are untested. \textbf{L9:} fixtures/cells support no population, safety-rate, or model-ranking inference. Internal validity requires independent policy expectations/no leakage; reproducibility requires pinned software/artifacts.
NPC deadlines, duplicate/stale/late-drop handling, cumulative budgets, and synchronous bindings are invariants, not measured latency/quality. Cancellation invalidates local state only; provider work may finish; \texttt{core.cancel} no-publication is unit/controller evidence, not a live-route guarantee. Fixed predicates/player requests; no human study, cross-world validation, independent gold labels, or C6 efficacy claim.

No participants or personal telemetry were collected. Planned human/affect work requires ethics review, consent, compensation disclosure, minimization, retention/deletion, and opt-out; LLM judges remain auxiliary and need calibration/bias controls \cite{S27_vanderlee2019best,S28_karpinska2021perils,S29_zheng2023judging,S30_chen2024judgement}.

\section{Conclusion}
\system{} gates payloads before mutation and audits outcomes via linked records/replay. Frozen fixtures establish conformance; live screening separates $\rho$ from blind retry (5/5 vs. 0/5) only in the constructed repairable regime and remains pilot-only. Godot readouts expose committed-snapshot rules/contributions; cross-model/player/retrieval/memory/affect/commercial benefits remain untested.
NPC is an implemented fixed-goal prototype: Python emits typed intent/public-projection BFS; Godot alone authorizes change. State movement, cumulative budgets, observation-only replanning, and zero-call replay are contract behavior, not efficacy or player-benefit claims.
