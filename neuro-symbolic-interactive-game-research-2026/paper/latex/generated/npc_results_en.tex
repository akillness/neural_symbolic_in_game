\subsection{Fixed-Goal NPC Operation (NPC-ENG1/NPC-SCR1)}
Mira's fixed goal is to deliver the authorized tide lead after harbor-signal restoration. Python computes bounded BFS plans from typed intent and public observations. Acquire/install remain player actions; the NPC may only commit the authorized \texttt{reveal\_hint}. Godot synchronously checks session/epoch/request/goal/policy/revision/hash before calling the existing writer without an await. Results and new observations determine the next plan, unlike single-candidate validator-error repair.

NPC-ENG1 comprises 16 deterministic R-arm engineering cases initialized from actual engine snapshots (assigned\_failure=2, completed=14). NPC-SCR1 retains all 72 assignments and failures, 24 per P/R/O arm (assigned\_failure=12, completed=60). P records 24 authenticated Codex CLI exec attempts, 24 returned decisions, and 4 assigned failures; these are not remote billing-call counts. Requested model: gpt-5.6-sol; recorded decision-model identifier: gpt-5.6-sol. The latter propagates the configured selector, not a provider revision; the provider revision is unavailable. Null identifiers remain unknown; global defaults are not evidence. Actual model-family matching is unverified. R uses authored rules. O's \texttt{same\_model\_family\_auxiliary} is a protocol source classification only and is non-independent; it does not establish that the actual models match. No source is independent; O is neither an oracle nor semantic gold. Table~\ref{tab:npc-screening} and Fig.~\ref{fig:npc-screening} report bounded protocol-conformance fixed-case counts, not recovery-efficacy, superiority, or generalization estimates. Efficacy remains pending; tokens and cost are unmeasured. A read-only CLI and isolated working directory were used, but tool-free inference and adversarial confidentiality were not established.
