\subsection{동결된 \texttt{reveal\_hint} 계약과 공개 증거}
이 산출물은 동결 기대값 패킷 \texttt{sl-npc-disclosure-expectations-v1} (v1.0.0)과 네 개의 실제 결과 파일만 소비한다. 패킷 SHA-256은 \texttt{9920aa834910a3ee\allowbreak{}35ed4446de4fdba4\allowbreak{}2bb67dda71b07a93\allowbreak{}bccfc7a0b2e09028}이며 sidecar와 직접 대조했다. 정상 분모는 선언식 \texttt{1 eligible actor x 4 declared fact IDs x 3 declared stage values x 2 knowledge values x 2 prior-disclosed values}의 48개이고, 경계 4개와 잘못된 입력 8개는 정상 분모에서 제외한다. 각 trace 행의 기대 객체는 gate 출력이 아니라 packet의 case ID에서 다시 대조했다.

내용 우선 설명은 typed input(연산·행위자·fact·stage·knowledge·prior-disclosed)에서 시작해 ontology entities/relations, authored rules, 실제 check 결과, allowed/denied 결정, canonical state effect 순으로 읽는다. 허용된 최초 표시는 요청 fact만(조석 단서이면 선언된 relationship-memory도) 추가하고 stage를 보존하며 revision을 한 번 올린다. 거부와 기공개 재표시는 canonical state를 바꾸지 않는다. 이 패널/그림은 설명용이며 hidden fact나 자연어 함의를 복원하거나 live capture를 주장하지 않는다.

온톨로지 선언은 \texttt{sl-npc-disclosur\allowbreak{}e-expectations-v\allowbreak{}1:runtime-disclo\allowbreak{}sure} / v1.0.0이며 provenance는 \texttt{frozen\_expectation\_packet}이다. 범위는 네 canonical fact ID(dock\_saved, keeper\_betrayal, lighthouse\_dark, tide\_marks\_hint)와 행위자 \texttt{captain\_mira}뿐이다. 규칙 ID는 DISC-001, DISC-002, DISC-003, DISC-004, DISC-005, DISC-006, DISC-007이고 승인 template은 \texttt{mira-safe-deflection-v1} 및 \texttt{sl-rc-003-authorized-hint}뿐이다.

Python evaluator는 같은 사례·기대 객체를 세 격리 arm에 materialize하고 semantic outcome, check trace, error, 상태 전후 SHA-256, template ID, replay equality를 기록한다. Godot은 별도 실행 경계에서 기존 \texttt{reveal\_hint} writer와 canonical mutation을 소유하며 이 producer는 이를 재구성하지 않는다. Python--Godot 연결은 operation \texttt{reveal\_hint}, scenario \texttt{sealed-lighthouse-v1}, actor \texttt{captain\_mira}, source hash로 추적한다.
실행 시점 관측 hash는 현재 source와 일치한다. 동결 패킷 baseline과 다른 source는 3개(game-track/godot/scripts/game3d/game\_3d.gd, game-track/godot/scripts/sealed\_lighthouse\_machine.gd, llm-wiki/wiki/reports/2026-10-22-ontology-signals-interview.md)이며, 패킷 hash는 수정하지 않고 이 차이를 공개한다.

표~\ref{tab:disclosure-arms}는 같은 60개 사례의 세 arm을 정상/경계/잘못된 입력 분모로 분리해 보고한다. unchecked 위반은 의도된 격리 관측이며 general-rule과 ontology-gate의 frozen expectation mismatch는 각각 0개이다. 그림~\ref{fig:disclosure-signals}는 기대 일치·재생 사례 계수(E/R), check-record PASS/FAIL 계수(C), 기록된 check가 없는 사례 수(NR)를 구별한다. NR은 skipped, pass, out-of-scope를 뜻하지 않는다. 표~\ref{tab:disclosure-fixtures}는 두 rule-change fixture와 네 paired case를 shipped scenario를 바꾸지 않는 disposable clone에 매핑한다.

주장은 bounded engineering conformance에 한정된다. human gold, access-separated holdout, efficacy, superiority, generalization, player benefit, model latent state 또는 cost를 주장하지 않는다. 정확한 입력 경로·hash·재생성 명령은 \path{paper/latex/generated/disclosure_producer_manifest.json}에 결속된다.
