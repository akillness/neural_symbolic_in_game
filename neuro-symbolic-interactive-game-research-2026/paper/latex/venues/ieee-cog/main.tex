\begin{abstract}
Generated game events can satisfy a syntactic schema and cite known facts while requesting inaccessible objects, unauthorized state transitions, or premature secret disclosure. \system{} separates proposal authority from commit authority via a deterministic seven-predicate gate, guided repair, and hash-linked replay (Theorems~1--4). Across 1,664 finite-graph cases, semantic gating eliminated 260/416 unsafe commits (0/156 false rejections; 128/260 repairs), while a 48-case multi-hop closure suite breaks 60/60 single-hop parity (48/48 ontology vs.\ 20/48 flat). Extended zero-LLM audits, 24 live Gemini episodes across three quest worlds (0/129 unsafe commits, 70 blocked turns, 24/24 strict replay, CLI revisions unattested), Stage-2 EN/KO escape checks (97.2\% recall, 0.0\% FRR), and a blinded \texttt{TR01--TR06} human-eval packet (\texttt{AWAITING\_}\allowbreak\texttt{HUMAN\_}\allowbreak\texttt{RATERS}) establish practical safety boundaries.
\end{abstract}
