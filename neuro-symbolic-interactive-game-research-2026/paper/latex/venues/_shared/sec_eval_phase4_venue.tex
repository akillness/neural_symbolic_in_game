Four core Phase-4 findings supersede earlier Phase-3 limits cleanly without altering frozen baselines:
(1) Using dynamic action/actor schema enums without answer hints (\textbf{P11}), \texttt{gpt-oss-120b-medium} actively executes across all five quest worlds (12 commits, 4 safe milestones, 2 live $\rho$ repairs), while \texttt{nesy\_game.multihop} holds unsafe turns to \textbf{0/79} across all three model families---eliminating multi-hop and epistemic leaks left unblocked by Safe-RL action masking (37/79 unsafe turns, $p{=}9.5{\times}10^{-7}$), NeMo-style Colang rails (43/79, $p{=}1.2{\times}10^{-7}$), and 1-hop flat gating (29/79, $p{=}3.81{\times}10^{-6}$).
(2) Eliminating the Phase-3/Phase-2 candidate-omission confound (\textbf{P12}), passing $(a, E)$ cleanly reveals that \emph{fairly conditioned} LLM self-repair already achieves near-parity accuracy on localized policy/stage faults (\textbf{26/27 = 96.3\%} for both State-Blind $K{=}2$ and State-Aware $K{=}2$ vs.\ \textbf{27/27 = 100.0\%} for $\rho_{K=2}$, McNemar $p{=}1.0$), isolating the true trade-off: deterministic $\rho_{K=2}$ removes 530k--542k tokens and $>$508\,s of latency per 27 faults, whereas bounded $K{=}2$ LLM re-proposal complements $\rho$ on Theorem~2 irreparable rejections by re-selecting valid alternative actions (52/55 safe re-targets, 0 unsafe commits).
(3) Without any recipe prompt hints (\textbf{P13}), Anthropic and Google models reach \textbf{10/10} unguided goals across the five Godot~4.7.1 worlds and \textbf{4/4} on production \texttt{SealedLighthouseMachine} (\texttt{EXACT\_TERMINAL\_HASH}), while GPT-OSS reaches 3/10 and 1/4 (42/42 fresh 0-LLM deterministic Godot replays match bit-identically with \textbf{0/42} leaks).
(4) Completing the open-weight GPT-OSS evaluation (\textbf{P14}) yields true 3-family, 4-model Stage-2 consensus (720 matrix evaluations, Fleiss' $\kappa{=}0.9367$), strictly separated from unexecuted $N{=}0$ human rating (\texttt{TR01--TR06} \texttt{AWAITING\_HUMAN\_RATERS}).
