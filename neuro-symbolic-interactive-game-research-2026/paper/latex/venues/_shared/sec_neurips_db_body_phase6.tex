\section{Benchmark Suite Composition, Curation, and Maintenance}\label{sec:db-composition}
\system{} is packaged as a standalone, zero-network-reproducible benchmark suite built around the frozen core (\texttt{src/nesy\_game/*.py}, 20/20 SHA-256 hashes unchanged) and \texttt{nesy\_game.multihop}. Following Gebru et al.~\cite{gebru2021datasheets} (\texttt{DATASHEET\_v6.md}) and ML Commons Croissant~1.0~\cite{akhtar2024croissant} (\texttt{croissant\_trace\_rpg\_benchmark\_v6.json}), the v6 archival bundle (refer to Supplement v6, \texttt{DATASHEET\_v6.md}, Croissant v6, and anonymized executable Godot~4.7.1 scripts with \texttt{reproduce\_benchmark.py --with-godot}; zero PII/IP/secret leaks) indexes verified \texttt{FileObject} artifacts across deterministic, solver, engine, and API tracks under dual \textbf{MIT} (verification harnesses, engine runners, and oracle code) and \textbf{CC BY 4.0} (traces, structured quest specs, and evaluation receipts) licenses. No web scraping or user-sourced text appears anywhere in the benchmark.

\textbf{Curation, attestation, and maintenance.} Deterministic tasks derive from symbolic quest state machines (${\le}8$ rooms, ${\le}3$ actors) and procedural $R{\le}256, d{\le}10$ multi-scale DAGs paired with EN/KO utterances. Direct HTTPS Phase-5 traces log \texttt{served\_model}, SHA-256-hashed message/request IDs, token counts, and HTTP latency under strict structured-JSON schemas (\texttt{temperature} omitted where deprecated on Claude~5.5); every parse/HTTP failure stays in full denominators. We disclose that Phase-5 live API trajectories (\textbf{P15}--\textbf{P17}) reflect a single provider family (Claude~5.5), which we contextualize against multi-family CLI traces (\textbf{P11}--\textbf{P14}) and vendor-agnostic symbolic/engine ground truth (\textbf{P9}, \textbf{P18}, \textbf{P19}, \textbf{P20}). Crucially, the blinded 36-item packet \texttt{TR01--TR06} ($N{=}0$ human gold labels; status \texttt{AWAITING\_HUMAN\_RATERS}) and historical unrun prospective pilot \texttt{20261103} ($0/180$; status \texttt{NOT\_RUN/BLOCKED}) are strictly quarantined from automated leaderboards, ensuring zero pseudo-human or fabricated ratings. Offline reproducibility is verified via \texttt{python3 reproduce\_benchmark.py} ($<5$\,s) and executable Godot~4.7.1 scripts via \texttt{--with-godot}.

Statistical testing confirms substantial separation across methods: Cochran's $Q = 871.39$ ($N=1,200, k=5, \mathrm{df}=4, p = 2.63\times 10^{-187}$), and exact McNemar test yields $p < 10^{-50}$ for Leave-One-Domain-Out (LODO) baselines over deterministic keyword rules. Crucially, naive keyword rules collapse under negated constraints (Strata S4 False Rejection Rate reaches 98.33\%), whereas character/word LODO models maintain $>97\%$ accuracy and balanced bilingual parity (EN 96.50\%, KO 97.83\%).

Together, \textbf{P9}, \textbf{P18}--\textbf{P20}, and \textbf{P15}--\textbf{P17} demonstrate the necessity of multi-tier neuro-symbolic verification: Safe-RL masking~\cite{alshiekh2018shield} and NeMo rails~\cite{rebedea2023nemo} fail multi-hop reachability in 14/15 episodes (\textbf{P15}); external solvers (\textbf{P18}) hit severe computational cliffs ($R{\ge}128$ for Z3, $R{\ge}64$ for OWL~2~RL) where \texttt{nesy\_game.multihop} sustains 0.032\,ms median latency and 100\% 60\,Hz/120\,Hz compliance; Godot~4.7.1 soak (\textbf{P19}) demonstrates zero-leak stability across 5,000 game ticks; and bilingual escape benchmarking (\textbf{P20}) establishes that robust natural language gating requires multi-hop semantic classification rather than superficial lexical filtering.
