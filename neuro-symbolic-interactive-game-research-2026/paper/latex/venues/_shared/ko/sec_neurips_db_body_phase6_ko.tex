\textbf{큐레이션, 인증 및 유지보수.} 결정론적 과제는 심볼릭 퀘스트 상태 기계(${\le}8$개 방, ${\le}3$명 행위자)와 한/영 발화가 결합된 $R{\le}256, d{\le}10$ 절차적 다중 스케일 DAG에서 유도된다. 직접 HTTPS 5단계 트레이스는 엄격한 구조화 JSON 스키마 하에 \texttt{served\_model}, SHA-256 해시된 메시지/요청 ID, 토큰 수 및 HTTP 지연시간을 기록하며(Claude~5.5에서 폐기된 \texttt{temperature} 생략), 모든 파싱/HTTP 실패는 전체 분모에 보존된다. 5단계 실시간 API 트레이스(\textbf{P15}--\textbf{P17})는 단일 벤더(Claude~5.5) 기반임을 투명하게 공개하며, 이는 다중 모델군 CLI 트레이스(\textbf{P11}--\textbf{P14}) 및 벤더 독립적 심볼릭/엔진 정답(\textbf{P9}, \textbf{P18}, \textbf{P19}, \textbf{P20})과 상호 보완적으로 배치된다. 특히 블라인드 36개 항목 패킷 \texttt{TR01--TR06}($N{=}0$ 인간 골드 라벨; 상태 \texttt{AWAITING\_HUMAN\_RATERS})과 과거 미실행 파일럿 \texttt{20261103}($0/180$; 상태 \texttt{NOT\_RUN/BLOCKED})은 자동화 리더보드에서 엄격히 격리되어 가짜 인간 라벨 생성을 원천 차단한다. 오프라인 재현성은 \texttt{python3 reproduce\_benchmark.py}($<5$초) 및 실행 가능 Godot~4.7.1 스크립트(\texttt{--with-godot})로 검증된다.

통계적 검정 결과는 기법 간 뚜렷한 격차를 확증한다: Cochran's $Q = 871.39$ ($N=1,200, k=5, \mathrm{df}=4, p = 2.63\times 10^{-187}$), 도메인 분리(LODO) 기준선 대 결정론적 규칙 간 McNemar 검정 $p < 10^{-50}$. 특히 단순 키워드 규칙은 부정 제약 조건에서 치명적으로 실패(S4 계층 오거부율 98.33\%)하는 반면, 문자/단어 LODO 모델은 97\% 이상의 높은 정확도와 균형 잡힌 한·영 언어적 패리티(영문 96.50\%, 한글 97.83\%)를 유지한다.

종합적으로 \textbf{P9}, \textbf{P18}--\textbf{P20}, 그리고 \textbf{P15}--\textbf{P17}은 다계층 뉴로-심볼릭 검증의 필수성을 입증한다: Safe-RL 마스킹~\cite{alshiekh2018shield}과 NeMo 레일~\cite{rebedea2023nemo}은 다중 홉 도달성에서 14/15회 실패하고(\textbf{P15}), 외부 범용 솔버(\textbf{P18})는 대규모 환경에서 극심한 연산 절벽(Z3의 경우 $R{\ge}128$, OWL~2~RL의 경우 $R{\ge}64$)에 직면하는 반면 \texttt{nesy\_game.multihop}은 중앙값 0.032\,ms로 100\% 60\,Hz/120\,Hz를 준수한다. 또한 Godot~4.7.1 장기 실행(\textbf{P19})은 5,000틱 무누출 안정성을 증명하며, 이중언어 탈출 벤치마크(\textbf{P20})는 표면 어휘 필터링을 넘어선 다중 홉 시맨틱 분류의 당위성을 확증한다.
