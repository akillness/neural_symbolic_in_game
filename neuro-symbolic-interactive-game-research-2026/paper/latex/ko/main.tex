\begin{abstract}
유창한 게임 대화만으로 실행 가능하고 승인된 상태 전이는 성립하지 않는다. \system{}은 생성 이벤트를 신뢰하지 않는 제안으로 취급한다. Strict parsing, 외부 policy, 여섯 계열의 일곱 술어, bounded repair, pre-commit revalidation이 변경을 gate한다. Typed-error 수리 $\rho$는 후보/오류만 읽고 authoritative state는 읽지 않는다. Unkeyed SHA-256 연결, semantic replay, complete accounting은 결과를 감사한다. 근거는 단일 world의 offline conformance, 단일 모델 live screening, 비권위적 closed-world graph simulation, 참여자 없는 Godot engineering으로 분리한다. Offline은 mechanism 근거뿐이다. $K{=}1$에서 guided/blind commit 5/5 대 0/5는 constructed repairable policy-blind regime에서만 관측됐다. Population efficacy, model superiority, player experience, commercial-engine performance는 어느 레인도 확립하지 않는다.
\end{abstract}

\section{서론}
자연스러운 이벤트도 없는 아이템 요구, 화자가 모르는 사실 주장, 금지 정보 공개, 비인가 효과, 퀘스트 단계 후퇴를 일으킬 수 있다. 실행 가능한 텍스트 환경은 그럴듯한 발화와 유효한 전이를 구분한다 \cite{S11_cote2019textworld,S12_wang2022scienceworld}. 근거 기반 대화·개인화 퀘스트가 보여 주는 퀘스트·엔터티·그래프 맥락의 가치도 \cite{S03_weir2024ontologically,S20_ashby2023personalized} 변경 권한은 아니다. \textbf{\system{}은 생성 이벤트를 신뢰하지 않는 트랜잭션 제안으로 취급하며, 외부의 결정론적 commit gate만 정식 상태 변경을 허용한다}(그림~\ref{fig:architecture}).


프로토콜 기여는 \textbf{C1---계약:} 버전형 신뢰경계 parsing(\ref{sec:arch}절; E1, ENG1); \textbf{C2---controller:} 검사, bounded repair, unchanged fallback, pre-commit revalidation(\ref{sec:repair}절; E1, ENG1); \textbf{C3---감사:} 연결된 semantic replay/continuity(\ref{sec:audit}절; E1, ENG1); \textbf{C4---harness:} proposal trace 없이도 assignment-complete 계수(\ref{sec:lanes}절; E1); \textbf{C5---수리:} typed $\rho(a,E)$ 대 blind retry/state-reading oracle(\ref{sec:repair}절; E1, E2)다. 표~\ref{tab:contribution-map}과~\ref{tab:evidence-lanes}는 기여·선례·레인·상한을 연결한다. Additive NPC-ENG1/NPC-SCR1은 descriptive이지 C6/C-RESULT가 아니며, \ref{sec:lanes}절은 ownership·분모·provenance·core Python--hard-policy/normal-play 경계를 고정한다.

\section{관련 연구와 연구 공백}
\subsection{인터랙티브 내러티브와 게임 에이전트}
KNUDGE는 quest/entity 명세 기반 대화 \cite{S03_weir2024ontologically}, graph quest \cite{S20_ashby2023personalized}, memory--reflection--planning \cite{S07_park2023generative}, 학습형 role agent \cite{S08_shao2023character}는 grounding/개연성을 다룬다. Player preference/dialogue quality 연구 \cite{S21_akoury2023player,S22_hochreiter2026beyond,S23_yin2026contextualized}와 2025년 preprint의 role-sensitive stability--improvisation trade-off \cite{S02_figueiredo2025scaffolded}는 hard admissibility와 자연스러움/player experience의 분리를 동기화한다.

경험 주도 생성·관찰자 표식 참여도·vision-language engagement 추론 한계는 future affect work의 동기지만 \cite{S24_yannakakis2011experiencedriven,S25_melhart2020engagement,S26_wang2026engagement}, affect는 비권위적이며 본문 구현에 없다.

\subsection{환경과 벤치마크}
TextWorld/ScienceWorld는 interactive state \cite{S11_cote2019textworld,S12_wang2022scienceworld}, MineDojo는 embodied task \cite{S13_fan2022minedojo}, GVGAI는 agent/game/content track을 제공한다 \cite{S14_perezliebana2019gvgai}. AgentBench, AgentBoard, SOTOPIA, BALROG는 이질적·과정 진단·사회적·장기 환경을 평가하며 \cite{S15_liu2024agentbench,S16_ma2024agentboard,S17_zhou2024sotopia,S18_paglieri2025balrog}, 자동 playtesting은 인간 평가를 보완한다 \cite{S19_lepelletier2022playtesting}. 검토 범위에서 transactional authorization, typed repair, semantic replay, complete accounting의 단일 결합은 식별하지 못했으나 최초성 주장은 아니다. NCP-Bench는 narrative commitment/fact consistency를 평가하지 \system{}이나 player outcome을 평가하지 않는다 \cite{S58_ma2026ncpbench}.

\subsection{제약, 신경-기호 검증, 검색}
구조 제약 \cite{S09_geng2023grammar,S10_beurerkellner2023prompting,S36_scholak2021picard}은 상태 상대 승인과 다르다. LLM-Modulo는 외부 sound critic \cite{S50_kambhampati2024llmmodulo}, SayCan은 skill affordance \cite{S51_ichter2023saycan}, AgentSpec은 trigger--predicate rule을 다룬다 \cite{S52_wang2025agentspec}. Setting the DC의 tool precondition 검사 \cite{S53_li2025settingdc}와 달리 본 연구는 proposal을 독립 policy에 대조한다. STORY2GAME은 precondition/effect를 생성하고 \cite{S54_zhou2025story2game}, PANGeA는 LLM rule judgement/refinement \cite{S42_buongiorno2024pangea}, IVIE는 incremental world의 symbolic validation \cite{S01_vaucher2026ivie}, 후속 연구는 authored transformation 제약을 사용한다 \cite{S44_gongora2026worldstate}. 이는 transaction/audit/repair 질문의 답이나 encoded predicate 밖 우월성 근거가 아니다. JSONSchemaBench의 structural compliance/coverage/quality도 semantic authorization을 확립하지 않는다 \cite{S57_geng2025jsonschemabench}.

G-Retriever, HippoRAG, Mem0는 subgraph retrieval과 장기 메모리를, Generative Agents와 Character-LLM은 행동 memory와 persona를 다룬다 \cite{S04_he2024gretriever,S05_gutierrez2024hipporag,S06_chhikara2025mem0,S07_park2023generative,S08_shao2023character}. \system{}은 이런 context를 받을 수 있지만 commit authority를 주지 않으며 효익은 측정하지 않았다.

\subsection{감사 가능성과 재현성}
과정 지표, sparse-run caution, reproducibility와 environmental reporting은 failure retention과 frozen artifact를 뒷받침한다 \cite{S16_ma2024agentboard,S31_agarwal2021precipice,S33_pineau2021reproducibility,S34_henderson2020energy}. Human/LLM 평가와 향후 participant 분석에는 construct/rater/bias control, justified margin과 random-effects 구조가 필요하다 \cite{S27_vanderlee2019best,S28_karpinska2021perils,S29_zheng2023judging,S30_chen2024judgement,S32_lakens2018equivalence,S35_barr2013random}. Record-and-replay는 경험 재사용을 지원하지만 \cite{S56_feng2025agentrr}, \system{}은 admitted transition의 semantic replay만 주장한다.
벤치마크 오염 완화 연구는 question-level leakage check의 필요성을 뒷받침하지만, 동결된 denominator를 변경하거나 game-agent efficacy 결과를 만들지는 않는다 \cite{S59_sun2025bdc}.

기여는 C1--C5의 결합이지 enforcement \cite{S52_wang2025agentspec}, game-state management \cite{S53_li2025settingdc,S54_zhou2025story2game}, feedback repair \cite{S45_madaan2023selfrefine}, replay \cite{S56_feng2025agentrr}, action interposition \cite{S37_riedl2003managing}, precondition/effect \cite{S39_fikes1971strips}, transition enforcement \cite{S40_schneider2000enforceable}, abort \cite{S49_haerder1983transaction}, social logic \cite{S38_evans2013versu}, belief-aware planning \cite{S41_ware2021sabre}의 발명이 아니다. 보고 누락은 구현 부재를 입증하지 않는다.

\section{문제 정의와 보장 경계}
시점 $t$의 validation 입력은 $c_t=(G_t,q_t)$다. $G_t$는 typed snapshot, $q_t$는 함께 저장된 외부 저작 action-policy/disclosure/quest-stage 제약이다. Terminal history $h_{<t}$는 \texttt{WorldState}와 별도이며 predicate는 읽지 않고 log로 상태를 복원하지도 않는다. 수락 전이는 $q_t$를 유지하고 $G_t$만 갱신한다. Policy rotation은 범위 밖이며 retrieval/narrative score/rationale/memory/미래 affect는 비권위적 proposal context다.

신뢰하지 않는 proposer가 후보 $a_t$를 출력한다. 타입 엄격 parsing은 알 수 없는 top-level field의 거부를 포함한 공유 candidate-key contract를 먼저 강제하고 선언 스키마를 확립한다. validator는 다음을 반환한다.
\begin{equation}
V(c_t,a_t)=(v_{\mathrm{policy}},v_{\mathrm{pre}},v_{\mathrm{reach}},
v_{\mathrm{know}},v_{\mathrm{disc}},v_{\mathrm{elig}},v_{\mathrm{stage}},E_t),
\end{equation}
여기서 $E_t$는 구조화 오류 집합이다. 상태 변경은 다음과 같다.
\begin{equation}
c_{t+1}=\begin{cases}
T(c_t,a_t), & \bigwedge_{i=1}^{7} v_i=1,\\
c_t, & \text{그 외.}
\end{cases}
\label{eq:transition}
\end{equation}

Deterministic valid/invalid/repair/fallback/replay/fault fixture는 일반 정리가 아닌 네 구현 불변량을 시험한다. \textbf{I1:} validation 소진이나 commit 전 proposal/controller 실패는 prior state를 반환한다. \textbf{I2:} callback이 반환하고 $K\geq0$이면 최대 $K+1$ recorded attempt와 성공 commit의 방어적 validation 한 번이다. Callback deadline을 강제하지 않아 wall-clock 종료 보장이 아니다. \textbf{I3:} 수락된 \texttt{CandidateAction.effects}는 \texttt{ActionPolicy.allowed\_effects} 안이며 quest-stage target도 policy가 명시 승인한다. \textbf{I4:} frozen schema/deterministic transition 아래 accepted trace는 명시된 terminal state를 복원한다.

가정은 올바른 policy, 후보 field로의 충실한 추출, deterministic version, callback 반환, 단일 프로세스 파일 소유다. Replay는 구조화 candidate/transition을 재검증하지만 중간 repair의 provenance/prompt/확률적 생성을 검증하지 \emph{않으며}, 구조화 field 밖 자연어 함의도 보장하지 않는다.

\subsection{신뢰 경계와 계약}

Versioned bridge는 observation/proposal/validation/rejection/fallback/commit을 전달하고 유효 commit만 정식 변경을 승인한다. Interface 분리는 상용 엔진 portability나 proposal-default/replay-parser 동등성을 입증하지 않으며 근거는 unknown-key rejection parity뿐이다.

\subsection{Validate--Repair--Commit}\label{sec:repair}
그림~\ref{alg:commit}의 무의존성 의사코드에서 ``Record''는 in-memory append이며, 영속 쓰기는 종단 일관성 검사 뒤다.

Repair는 structured error code를 받고 상태를 직접 바꾸지 않으며 소진 시 변경 없는 결정론적 fallback을 반환한다(그림~\ref{fig:architecture}). 두 callback 중 \emph{typed validator-error-guided 연산자}(\texttt{counterexample\_guided\_repair})는 직전 후보 $a$와 typed 오류 $E$만 읽고, 이 오류가 유일한 상태 유래 입력이며 \texttt{WorldState}에 직접 접근하지 않는다.
\begin{equation}
\rho(a,E)=a \oplus \textstyle\bigcup_{e\in E}\delta(e),
\label{eq:rho}
\end{equation}
$\delta(e)$는 표~\ref{tab:rho-rules}의 결정론적 class별 edit, $\oplus$는 field edit 적용이다. 오류 entity당 최대 한 field를 바꾸므로 시도당 변경 field는 $|E|$ 이하이며, 동일한 $E$를 두 번 적용할 때만 고정점이다(변하는 오류/시도의 수렴 아님). 같은 field에서 요구와 거부가 겹친 entity는 irreparable로 두고 바꾸지 않는다. \emph{State-reading 참조 callback}은 오류를 버리고 authoritative state에서 policy-governed precondition/effect/두 quest-stage field를 복원한다. Required object/used fact/disclosed fact의 선언 무결성 field는 바꾸지 않는다. 의존성·disclosure 삭제는 수리가 아닌 위반 세탁이기 때문이다. 이는 상태 판독 oracle 상한이지 배포 가능한 수리의 근거가 아니다.

\subsection{무결성, 의미적 리플레이, 계수}\label{sec:audit}
Result row의 키 없는 SHA-256 \emph{무결성 checksum}과 proposal의 trace-checksum 연결은 우발적·시험 대상 변경을 탐지한다. Signature/MAC/writer identity가 아니며 content와 checksum을 함께 재작성하는 행위자를 막지 못한다. Semantic replay는 prior state와 모든 candidate/validation pair를 엄격 parsing하고 nonfinal attempt의 invalid, terminal transition 재계산·final state 일치, 인접 JSONL state continuity를 요구한다. Candidate $j+1$의 repair-generation은 인증·재실행하지 않는다. Request$\rightarrow$decision$\rightarrow$result 순서와 첫 issued action의 정확히 한 receipt 결합을 검사하지만 duplicate-action-ID 발행 금지나 cryptographic authentication을 주장하지 않는다.

Terminal class는 commit, symbolic fallback, adapter failure, controller failure다. Controller failure는 상태와 assignment 분모를 보존하되 candidate outcome이 없으면 proposal trace도 없을 수 있으므로 result 완전성이 row별 trace를 뜻하지 않는다. 실행 전 key는 $(\mathrm{run},\allowbreak\mathrm{arm},\allowbreak\mathrm{scenario},\allowbreak\mathrm{seed},\allowbreak\mathrm{model},\allowbreak\mathrm{revision},\allowbreak h_{\mathrm{controller}},\allowbreak h_{\mathrm{input}},\allowbreak h_{\mathrm{prior}})$다. 집계는 중복/누락/예기치 않은 key를 거부하고 symbolic/adapter/controller failure를 분리한다.

\section{논의}
\subsection{확립 가능한 범위}
동결 pilot은 mechanism behavior만 확립한다. encoded check의 state isolation, 선언된 repair/fallback 경로, 명명된 corruption 거부와 row classification을 확인하며 안정적인 detector 귀속은 하지 않는다.
NPC 경계와 ownership은 \ref{sec:lanes}절에 고정된다. Count는 descriptive이며 efficacy, superiority, generalization, human benefit, cost equality, semantic gold 또는 accuracy ceiling을 추정하지 않는다.

Offline state-reading은 $\rho$가 전환할 수 없는 oracle-only 사례를 처리하고, typed error만 쓰는 $\rho$는 guided-repairable class에서 oracle과 일치한다. Live에서 blind retry와의 분리는 그 regime에서만 나타났으며 already-valid/irreparable null, unpinned revision과 quasi-replicated calls는 sample-efficiency/model-capability 주장을 막는다. Self-Refine, Reflexion, Self-Debugging이 선례지만 \cite{S45_madaan2023selfrefine,S48_shinn2023reflexion,S46_chen2023selfdebug}, $\rho$는 deterministic pre-execution error만 소비하고 실패 arm을 격리하며 semantic repair가 아니라 counterexample-guided synthesis와 유사할 뿐이다 \cite{S47_solarlezama2006sketching}.
\noindent\textbf{공개 결과의 해석.} NPC-DISC-1 결과는 same-rule agreement와 bounded migration diagnostics로 읽는다. \texttt{general\_rule}과 \texttt{ontology\_gate}의 판정 일치는 두 구현이 frozen case를 일관되게 실현했다는 뜻이지 ontology가 우월·완전·필수라는 뜻이 아니다. Rule-change fixture는 declaration/code 수정 범위와 paired case 누락을 드러낸다. signal 그림과 표는 관측 case outcome과 state-delta assertion을 보고할 뿐 모델 내부 잠재 상태나 임의 prose의 누출 부재를 증명하지 않는다.

\subsection{선행연구와의 관계}

\system{}은 constrained decoding, retrieval/memory, 실행 benchmark, process-linked 측정을 보완한다. 미실행 계획은 독립 semantic oracle/blind retry의 사전등록 다중 모델 비교, matched-validity retrieval/memory ablation, 검정력·mixed-effects를 갖춘 blinded matched-validity 인간 연구이며 screening은 이를 대체하지 않는다 \cite{S27_vanderlee2019best,S31_agarwal2021precipice,S35_barr2013random}.

\section{타당성 위협, 윤리, 산출물 범위}
경계는 아홉 가지다. \textbf{L1:} structured field 밖 의미·행동 일관성과 서사 품질은 미측정이다 \cite{S55_huang2026beyond}; \textbf{L2:} world/live-state 하나로 cross-world/cross-policy/scale 일반화는 안 된다; \textbf{L3:} state-reading은 oracle이며 class/regime은 repair 품질/sample efficiency를 입증하지 않는다; \textbf{L4:} hosted proposer의 revision/seed는 미고정·token 회계가 없고 E2는 Python--Godot authorization round trip이 없다; \textbf{L5:} 참여자, 정서, 이해, 행위 주체성, 즐거움, 몰입, 효익 근거가 없다; \textbf{L6:} unkeyed hash는 integrity이지 authentication/tamper resistance가 아니다; \textbf{L7:} single-writer 외 concurrent-writer safety는 미검증이다; \textbf{L8:} startup-dominated Godot fixture의 16.7\,ms 초과 sample은 portability/performance 결과가 아니다; \textbf{L9:} 선택 fixture/cell은 population/safety-rate/model-ranking 추론을 지지하지 않는다. Internal validity는 독립 policy expectation/leakage 부재, 재현성은 frozen software/artifact에 의존한다.
NPC asynchronous deadline, duplicate/stale/late-drop, cumulative budget, synchronous binding은 latency/quality가 아닌 protocol invariant다. \ref{sec:arch}절은 local-only cancellation/provider-completion과 unit/controller-only \texttt{Core.cancel} 경계를 고정하며 human/cross-world/independent-gold/oracle/recovery efficacy 근거를 만들지 않는다. 현재 pilot은 participant/personal telemetry를 처리하지 않으며, planned human/affect work에는 review, consent, compensation disclosure, minimization, retention/deletion, opt-out, calibrated/bias-controlled auxiliary LLM judge가 필요하다 \cite{S27_vanderlee2019best,S28_karpinska2021perils,S29_zheng2023judging,S30_chen2024judgement}.
NPC-DISC-1의 공개 보장은 frozen canonical ID, approved template, 유한 state 축으로 좁다. Free-form/implicit inference, hidden payload, 모든 UI 채널의 leakage-free를 증명하지 않으며, 기대 packet은 declaration-derived human gold/holdout이 아니다. Jev는 advisory이며 label·commit 권한이 없다.

\section{결론}
\system{}은 mutation을 gate하고 linked record/replay를 감사한다. Frozen fixture는 적합성, pilot-only screening은 constructed repairable regime에서만 $\rho$/blind retry의 5/5 대 0/5를 보여 준다. NPC-DISC-1은 폐쇄형 \texttt{reveal\_hint} 계약·세 arm·유한 strata·기공개 no-mutation 검사를 추가한다. 표/그림은 expectation을 gold/효능으로 바꾸지 않는다. Cross-model/player/retrieval/memory/affect/commercial benefit은 미검증이며 \ref{sec:lanes}절은 additive NPC/historical \texttt{native012}/legacy ENG1을 분리한다.
