\begin{abstract}
대규모 언어 모델은 표현력 있는 퀘스트와 대화를 생성할 수 있지만, 유창하거나 스키마에 맞는 텍스트만으로 제안 이벤트의 실행 가능성, 권한 적합성, 정식 게임 상태와의 일관성이 성립하지는 않는다. 본 논문은 생성된 이벤트를 신뢰하지 않는 트랜잭션 제안으로 취급하는 기호 커밋 게이트 \system{}을 제안한다. 타입 엄격 parser, 외부 행동 정책, 여섯 상태 상대 계열로 묶인 일곱 개의 결정론적 검사가 각 전이를 결정하며, 실패 후보는 최대 $K+1$개의 기록된 시도 안에서 제한 수리로 보낼 수 있고 통과 후보는 변경 직전에 다시 검증한다. Validator-error-guided 연산자 $\rho$는 직전 후보와 typed validation error만 읽으며, 이 오류가 유일한 상태 유래 입력이고 권위 있는 \texttt{WorldState}에 직접 접근하지 않는다. 키 없는 SHA-256 콘텐츠 연결, 상태 의미 replay, 할당 완전 계수가 terminal outcome을 감사 가능하게 만든다. 근거는 네 레인으로 분리한다: 단일 작성 world의 오프라인 적합성, 단일 모델 라이브 스크리닝, runtime 권한 없는 closed-world 지식 그래프 링크 시뮬레이션, 참여자가 없는 Godot engineering slice. 오프라인 레인은 mechanism 적합성만 확립한다. 라이브 레인은 $K{=}1$에서 의도적으로 수리 가능하게 만든 policy-blind regime에 한해 guided 5/5 대 blind 0/5 commit을 관찰했으므로 pilot-only로 남는다. 어느 레인도 모집단 효능, 모델 우월성, 플레이어 경험, 상용 엔진 성능을 확립하지 않는다.
\end{abstract}

\section{서론}
자연스러운 이벤트도 없는 아이템 요구, 화자가 모르는 사실 주장, 금지 정보 공개, 비인가 효과, 퀘스트 단계 후퇴를 일으킬 수 있다. 실행 가능한 텍스트 환경은 그럴듯한 발화와 유효한 전이를 구분한다 \cite{S11_cote2019textworld,S12_wang2022scienceworld}. 근거 기반 대화·개인화 퀘스트가 보여 주는 퀘스트·엔터티·그래프 맥락의 가치도 \cite{S03_weir2024ontologically,S20_ashby2023personalized} 변경 권한은 아니다. \textbf{\system{}은 생성 이벤트를 신뢰하지 않는 트랜잭션 제안으로 취급하며, 외부의 결정론적 commit gate만 정식 상태 변경을 허용한다}(그림~\ref{fig:architecture}).

문법 제약 디코딩, 모델 질의 언어, 점진 parser는 구조를 제한하지만 \cite{S09_geng2023grammar,S10_beurerkellner2023prompting,S36_scholak2021picard} 현재 세계에 대한 진실을 보장하지 않는다. 검색과 메모리도 근거를 공급할 뿐 \cite{S04_he2024gretriever,S05_gutierrez2024hipporag,S06_chhikara2025mem0} 상태 전이를 승인하지 않는다.

감사 가능한 트랜잭션 프로토콜의 기여는 \textbf{C1---계약:} 버전형 신뢰경계 contract/type-strict parser(unknown key·모호한 타입 거부; \ref{sec:arch}절; E1, ENG1); \textbf{C2---controller:} 여섯 상태 상대 계열의 검사 7개, bounded repair, unchanged fallback, pre-commit revalidation(\ref{sec:repair}절; E1, ENG1); \textbf{C3---감사:} SHA-256 연결 record, state-semantic replay, episode continuity(\ref{sec:audit}절; E1, ENG1); \textbf{C4---harness:} proposal trace가 없어도 분류된 terminal row를 보존하는 assignment-complete 오프라인 적합성(\ref{sec:lanes}절; E1); \textbf{C5---수리:} 동결 repairability class에서 blind retry/state-reading oracle과 비교한 typed $\rho(a,E)$(\texttt{counterexample\_guided\_repair}; \ref{sec:repair}절; E1, E2)다.
고정 목표 NPC는 C6/C-RESULT가 아닌 additive implementation·descriptive NPC-ENG1/NPC-SCR1이며, core Python--hard-policy 및 normal-play와의 경계·ownership·count·role gate·provenance는 \ref{sec:lanes}절에 고정한다. 기계 검증 매트릭스의 표~\ref{tab:contribution-map}과~\ref{tab:evidence-lanes}는 C1--C5의 선행 주제, 레인, 추론 상한을 연결한다.

\section{관련 연구와 연구 공백}
\subsection{인터랙티브 내러티브와 게임 에이전트}
KNUDGE는 퀘스트·엔터티 명세 기반 분기형 NPC 대화를 평가한다 \cite{S03_weir2024ontologically}. 지식 그래프 퀘스트 \cite{S20_ashby2023personalized}, 메모리--성찰--계획 \cite{S07_park2023generative}, 학습형 역할 에이전트 \cite{S08_shao2023character}는 근거성과 개연성을 보완한다. 플레이어 선호·지각된 대화 품질 연구 \cite{S21_akoury2023player,S22_hochreiter2026beyond,S23_yin2026contextualized}와 역할별 안정성--즉흥성 trade-off를 보고한 2025년 프리프린트 \cite{S02_figueiredo2025scaffolded}는 하드 허용 가능성과 선택적 자연스러움·플레이어 경험의 분리를 동기화한다.

경험 주도 생성·관찰자 표식 참여도·vision-language engagement 추론 한계는 future affect work의 동기지만 \cite{S24_yannakakis2011experiencedriven,S25_melhart2020engagement,S26_wang2026engagement}, affect는 비권위적이며 본문 구현에 없다.

\subsection{환경과 벤치마크}
TextWorld와 ScienceWorld는 명시적 인터랙티브 상태 \cite{S11_cote2019textworld,S12_wang2022scienceworld}, MineDojo는 개방형 지식 집약 embodied 과제 \cite{S13_fan2022minedojo}, General Video Game AI는 에이전트·게임·콘텐츠별 트랙을 제공한다 \cite{S14_perezliebana2019gvgai}. AgentBench는 이질적 환경 \cite{S15_liu2024agentbench}, AgentBoard는 과정 진단 \cite{S16_ma2024agentboard}, SOTOPIA는 사회적 상호작용 \cite{S17_zhou2024sotopia}, BALROG는 장기 언어·시각 게임 추론을 평가한다 \cite{S18_paglieri2025balrog}. 자동 플레이 스타일 에이전트는 인간 평가의 보완재이지 대체재가 아니다 \cite{S19_lepelletier2022playtesting}. 검토 범위에서 transactional authorization, typed repair, semantic replay, assignment-complete accounting을 한 protocol로 결합한 사례는 식별하지 못했으나 최초성 주장은 아니다.
NCP-Bench는 장기 인터랙티브 내러티브의 commitment와 fact consistency를 위한 benchmark를 추가하지만, \system{}이나 플레이어 결과를 평가하지 않는다 \cite{S58_ma2026ncpbench}.

\subsection{제약, 신경-기호 검증, 검색}
제약 디코더는 구조를 개선한다 \cite{S09_geng2023grammar,S10_beurerkellner2023prompting,S36_scholak2021picard}; \system{}은 독립적 상태 상대 승인을 요구한다. Generate-and-verify 선례는 LLM-Modulo의 모델 제안 계획/외부 sound critic \cite{S50_kambhampati2024llmmodulo}, SayCan의 상태 의존 skill-affordance 검사다 \cite{S51_ichter2023saycan}. AgentSpec의 trigger--predicate--enforcement 규칙 \cite{S52_wang2025agentspec}과 달리 여기서는 game-state 술어, 수리 계약, replay record를 결합한다. Setting the DC는 D\&D agent를 precondition 검사 tool call에 근거시키고 \cite{S53_li2025settingdc}, 우리는 자유 텍스트를 parsing/외부 policy 뒤에 허용한다. STORY2GAME은 LLM이 action precondition/effect를 생성하지만 \cite{S54_zhou2025story2game}, 여기서는 독립 저작 policy의 결정론적 critic이 typed 반례를 반환한다. PANGeA는 LLM의 설계자 규칙별 판정·수정 \cite{S42_buongiorno2024pangea}, IVIE는 기호 검증 기반 점진 세계 생성 \cite{S01_vaucher2026ivie}, 2026년 후속 시스템은 저작된 world-state transformation 선택 제한으로 구성상 일관성을 얻는다 \cite{S44_gongora2026worldstate}. 트랜잭션·감사 record·수리 연산자는 별도 근거 대상이다. 비교는 우월성을 뜻하지 않으며 유효성은 인코딩 술어에 한정된다.
JSONSchemaBench는 구조적 constrained-output compliance, coverage, quality를 측정하지만, 이는 상태 상대 semantic authorization을 확립하지 않는다 \cite{S57_geng2025jsonschemabench}.

G-Retriever, HippoRAG, Mem0는 subgraph retrieval과 장기 메모리를, Generative Agents와 Character-LLM은 행동 memory와 persona를 다룬다 \cite{S04_he2024gretriever,S05_gutierrez2024hipporag,S06_chhikara2025mem0,S07_park2023generative,S08_shao2023character}. \system{}은 이런 context를 받을 수 있지만 commit authority를 주지 않으며 효익은 측정하지 않았다.

\subsection{감사 가능성과 재현성}
과정 지표, sparse-run caution, reproducibility와 environmental reporting은 failure retention과 frozen artifact를 뒷받침한다 \cite{S16_ma2024agentboard,S31_agarwal2021precipice,S33_pineau2021reproducibility,S34_henderson2020energy}. Human/LLM 평가와 향후 participant 분석에는 construct/rater/bias control, justified margin과 random-effects 구조가 필요하다 \cite{S27_vanderlee2019best,S28_karpinska2021perils,S29_zheng2023judging,S30_chen2024judgement,S32_lakens2018equivalence,S35_barr2013random}. Record-and-replay는 경험 재사용을 지원하지만 \cite{S56_feng2025agentrr}, \system{}은 admitted transition의 semantic replay만 주장한다.
벤치마크 오염 완화 연구는 question-level leakage check의 필요성을 뒷받침하지만, 동결된 denominator를 변경하거나 game-agent efficacy 결과를 만들지는 않는다 \cite{S59_sun2025bdc}.

Novelty는 선행 요소의 구현된 결합이다: runtime enforcement \cite{S52_wang2025agentspec}, symbolic game-state management \cite{S53_li2025settingdc,S54_zhou2025story2game}, feedback repair \cite{S45_madaan2023selfrefine}, record/replay \cite{S56_feng2025agentrr}, action interposition \cite{S37_riedl2003managing}, classical preconditions/effects \cite{S39_fikes1971strips}, permitted-transition enforcement \cite{S40_schneider2000enforceable}, transaction abort \cite{S49_haerder1983transaction}, authored social logic \cite{S38_evans2013versu}, belief-aware narrative planning \cite{S41_ware2021sabre}. C1--C5는 game-state commit 경계에 독립 contract, validate--repair--commit, checksum-linked semantic replay/continuity, complete accounting, typed-error repair를 결합한다. 보고 누락은 구현 부재를 뜻하지 않는다.

\section{문제 정의와 보장 경계}
설명을 위해 시점 $t$에서 validation이 사용하는 controller 입력을 다음과 같이 분해한다.
\begin{equation*}
c_t=(G_t,q_t),
\end{equation*}
$G_t$는 typed snapshot field, $q_t$는 함께 저장된 외부 저작 action-policy·disclosure·quest-stage 제약이다. 종단 history $h_{<t}$는 \texttt{WorldState}와 별도이며 predicate는 이를 읽지 않고 log에서 상태를 복원하지도 않는다. 수락된 one-step 전이는 $q_t$를 유지하며 $G_t$만 갱신한다. 정책 버전 교체는 범위 밖이며 검색·내러티브 점수·모델 rationale·메모리 요약·미래 affect는 비권위적 proposal context다.

신뢰하지 않는 proposer가 후보 $a_t$를 출력한다. 타입 엄격 parsing은 알 수 없는 top-level field의 거부를 포함한 공유 candidate-key contract를 먼저 강제하고 선언 스키마를 확립한다. validator는 다음을 반환한다.
\begin{equation}
V(c_t,a_t)=(v_{\mathrm{policy}},v_{\mathrm{pre}},v_{\mathrm{reach}},
v_{\mathrm{know}},v_{\mathrm{disc}},v_{\mathrm{elig}},v_{\mathrm{stage}},E_t),
\end{equation}
여기서 $E_t$는 구조화 오류 집합이다. 상태 변경은 다음과 같다.
\begin{equation}
c_{t+1}=\begin{cases}
T(c_t,a_t), & \bigwedge_{i=1}^{7} v_i=1,\\
c_t, & \text{그 외.}
\end{cases}
\label{eq:transition}
\end{equation}

인코딩 계약의 구현 불변량은 일반 정리가 아니라 deterministic valid/invalid/repair/fallback/replay/fault-injection fixture로 시험한다. \textbf{I1 (소진 실패 불변성):} 예산 $K$까지 유효 후보가 없거나 commit 전 proposal/controller가 실패하면 반환 상태는 prior state다. \textbf{I2 (제한된 기록 시도):} 모든 proposal/repair callback이 반환할 때 $K\geq0$은 최대 $K+1$ candidate attempt를 기록하고 성공 commit은 변경 직전 방어적 validation을 한 번 더 한다. Callback deadline을 강제하지 않으므로 wall-clock 종료 보장은 아니다. \textbf{I3 (효과 권한):} 수락된 \texttt{CandidateAction.effects}의 선언 fact effect는 \texttt{ActionPolicy.allowed\_effects} 안에 있고 quest-stage target도 policy가 명시적으로 승인한다. \textbf{I4 (상태 의미적 리플레이):} 동결 schema·결정론적 전이 아래 수락 trace는 명시된 terminal state를 복원한다.

이 주장된 불변량은 올바른 정책 작성, 선언된 후보 필드로의 완전하고 충실한 추출, 결정론적 소프트웨어 버전, callback 반환, 단일 프로세스 파일 소유권을 가정한다. 상태 의미적 리플레이는 기록된 구조화 후보와 전이를 재검증하지만, 중간 수리의 provenance, reasoning, prompt, 확률적 생성은 재현하거나 검증하지 \emph{않는다}. 구조화 필드에서 누락된 자연어 함의는 보장 범위 밖이다.

\section{TRACE-RPG 아키텍처와 알고리즘}\label{sec:arch}
\subsection{신뢰 경계와 계약}
모델/recorded adapter는 canonical owner 밖이다(그림~\ref{fig:architecture}). Parser는 모호한 숫자·collection type과 unknown top-level field를 거부하며 별도 policy는 required precondition/allowed effect를 정의한다. \begin{tabular}{@{}rl@{}}

Repair는 structured error code를 받고 상태를 직접 바꾸지 않으며 소진 시 변경 없는 결정론적 fallback을 반환한다(그림~\ref{fig:architecture}). 두 callback 중 \emph{typed validator-error-guided 연산자}(\texttt{counterexample\_guided\_repair})는 직전 후보 $a$와 typed 오류 $E$만 읽고, 이 오류가 유일한 상태 유래 입력이며 \texttt{WorldState}에 직접 접근하지 않는다.
\begin{equation}
\rho(a,E)=a \oplus \textstyle\bigcup_{e\in E}\delta(e),
\label{eq:rho}
\end{equation}
$\delta(e)$는 표~\ref{tab:rho-rules}의 결정론적 class별 edit, $\oplus$는 field edit 적용이다. 오류 entity당 최대 한 field를 바꾸므로 시도당 변경 field는 $|E|$ 이하이며, 동일한 $E$를 두 번 적용할 때만 고정점이다(변하는 오류/시도의 수렴 아님). 같은 field에서 요구와 거부가 겹친 entity는 irreparable로 두고 바꾸지 않는다. \emph{State-reading 참조 callback}은 오류를 버리고 authoritative state에서 policy-governed precondition/effect/두 quest-stage field를 복원한다. Required object/used fact/disclosed fact의 선언 무결성 field는 바꾸지 않는다. 의존성·disclosure 삭제는 수리가 아닌 위반 세탁이기 때문이다. 이는 상태 판독 oracle 상한이지 배포 가능한 수리의 근거가 아니다.

\subsection{무결성, 의미적 리플레이, 계수}\label{sec:audit}
Result row의 키 없는 SHA-256 \emph{무결성 checksum}과 proposal의 trace-checksum 연결은 우발적·시험 대상 변경을 탐지한다. Signature/MAC/writer identity가 아니며 content와 checksum을 함께 재작성하는 행위자를 막지 못한다. Semantic replay는 prior state와 모든 candidate/validation pair를 엄격 parsing하고 nonfinal attempt의 invalid, terminal transition 재계산·final state 일치, 인접 JSONL state continuity를 요구한다. Candidate $j+1$의 repair-generation은 인증·재실행하지 않는다. Request$\rightarrow$decision$\rightarrow$result 순서와 첫 issued action의 정확히 한 receipt 결합을 검사하지만 duplicate-action-ID 발행 금지나 cryptographic authentication을 주장하지 않는다.

Terminal class는 commit, symbolic fallback, adapter failure, controller failure다. Controller failure는 상태와 assignment 분모를 보존하되 candidate outcome이 없으면 proposal trace도 없을 수 있으므로 result 완전성이 row별 trace를 뜻하지 않는다. 실행 전 key는 $(\mathrm{run},\allowbreak\mathrm{arm},\allowbreak\mathrm{scenario},\allowbreak\mathrm{seed},\allowbreak\mathrm{model},\allowbreak\mathrm{revision},\allowbreak h_{\mathrm{controller}},\allowbreak h_{\mathrm{input}},\allowbreak h_{\mathrm{prior}})$다. 집계는 중복/누락/예기치 않은 key를 거부하고 symbolic/adapter/controller failure를 분리한다.

Exception만으로 안정적 detector layer를 식별할 수 없어 귀속은 보고하지 않고 fixture에 $p$-value/모집단 interval도 붙이지 않는다. Adapter latency/token은 JSON-Schema \texttt{const} 합성값으로 계수 전파만 확인하며 provider/runtime/device 측정이 아니다. \section{논의}
\subsection{확립 가능한 범위}
동결 pilot은 mechanism behavior만 확립한다. encoded check의 state isolation, 선언된 repair/fallback 경로, 명명된 corruption 거부와 row classification을 확인하며 안정적인 detector 귀속은 하지 않는다.
NPC 경계와 ownership은 \ref{sec:lanes}절에 고정된다. Count는 descriptive이며 efficacy, superiority, generalization, human benefit, cost equality, semantic gold 또는 accuracy ceiling을 추정하지 않는다.

Offline state-reading은 $\rho$가 전환할 수 없는 oracle-only 사례를 처리하고, typed error만 쓰는 $\rho$는 guided-repairable class에서 oracle과 일치한다. Live에서 blind retry와의 분리는 그 regime에서만 나타났으며 already-valid/irreparable null, unpinned revision과 quasi-replicated calls는 sample-efficiency/model-capability 주장을 막는다. Self-Refine, Reflexion, Self-Debugging이 선례지만 \cite{S45_madaan2023selfrefine,S48_shinn2023reflexion,S46_chen2023selfdebug}, $\rho$는 deterministic pre-execution error만 소비하고 실패 arm을 격리하며 semantic repair가 아니라 counterexample-guided synthesis와 유사할 뿐이다 \cite{S47_solarlezama2006sketching}.
\subsection{선행연구와의 관계}

\system{}은 constrained decoder \cite{S09_geng2023grammar,S10_beurerkellner2023prompting,S36_scholak2021picard}, 검색/메모리 \cite{S04_he2024gretriever,S05_gutierrez2024hipporag,S06_chhikara2025mem0}, 실행 환경/benchmark를 보완한다 \cite{S11_cote2019textworld,S12_wang2022scienceworld,S15_liu2024agentbench,S18_paglieri2025balrog}. Process-linked trace는 AgentBoard의 측정 관심사 \cite{S16_ma2024agentboard}이지 우월성 근거가 아니다. 미실행 확증 계획은 독립 semantic oracle·실제 blind-retry의 사전등록 다중 모델 비교, matched-validity retrieval/memory ablation, 검정력·mixed-effects를 갖춘 blinded matched-validity 인간 연구이며 screening은 이를 대체하지 않는다 \cite{S27_vanderlee2019best,S31_agarwal2021precipice,S35_barr2013random}.

\section{타당성 위협, 윤리, 산출물 범위}
경계는 아홉 가지다. \textbf{L1:} structured field 밖 의미·행동 일관성은 못 보며 서사 품질은 미측정이다 \cite{S55_huang2026beyond}. \textbf{L2:} world/live-state variant 하나로 cross-world/cross-policy/scale 일반화는 안 된다. \textbf{L3:} state-reading은 oracle이며 class/regime은 일반 repair 품질/sample efficiency를 입증하지 않는다. \textbf{L4:} hosted proposer 하나의 revision/seed는 미고정, token 회계는 없고 E2는 Python--Godot authorization round trip을 측정·benchmark하지 않는다. \textbf{L5:} participant/affect data가 없어 engine-local 적합성·measurement-ready protocol일 뿐 comprehension/agency/enjoyment/immersion/player benefit 근거가 아니다. \textbf{L6:} unkeyed hash는 integrity이지 writer authentication/adversarial tamper resistance가 아니다. \textbf{L7:} single-writer 가정으로 concurrent-writer safety는 미검증이다. \textbf{L8:} startup-dominated Godot fixture 하나의 16.7\,ms 초과 sample은 portability/real-time 결과가 아니다. \textbf{L9:} 선택 fixture/cell은 population/safety-rate/model-ranking 추론을 지지하지 않는다. Internal validity는 독립 policy expectation/leakage 부재, 재현성은 frozen software/artifact에 의존한다.
NPC asynchronous deadline, duplicate/late-drop, session/epoch/goal/policy/revision/hash freshness는 latency/quality 아닌 protocol invariant다. Live 취소는 local HTTP/directive invalidation이므로 provider 완료나 server bounded trace/cache가 남을 수 있다. \texttt{Core.cancel} no-publication은 unit/controller-only이지 live-route 보장이 아니다. Game contract의 final predicate/player-request는 human/cross-world/independent semantic gold/oracle/recovery efficacy 근거가 아니다. Zero-model-call epoch replay와 native immutable-input \texttt{--npc-experiment} 경로의 \texttt{engine\_fixture\_reexecution}(\texttt{--npc-replay} 아님)은 \ref{sec:arch}절을 따른다.

현재 pilot은 participant 또는 personal telemetry를 처리하지 않는다. Human/affect study와 LLM/crowd judge는 아직 실행하지 않은 planned work이며, 향후 review, informed consent, compensation disclosure, minimization, retention/deletion rule, opt-out, judge calibration과 bias control이 필요하다 \cite{S27_vanderlee2019best,S28_karpinska2021perils,S29_zheng2023judging,S30_chen2024judgement}.

\section{결론}
\system{}은 mutation을 gate하고 linked record/replay를 감사한다. Frozen fixture는 적합성, pilot-only screening은 constructed repairable regime에서만 $\rho$/blind retry의 5/5 대 0/5를 보여 준다. Godot readout은 committed-snapshot rule/contribution을 드러내지만 cross-model/player/retrieval/memory/affect/commercial benefit은 미검증이다. \ref{sec:lanes}절의 additive NPC/historical \texttt{native012}(post-fix 재검증 아님)/legacy ENG1은 contract/provenance이지 production-readiness/generalization/efficacy/player-benefit 주장이 아니다.
