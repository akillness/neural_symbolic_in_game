## 초록

대규모 언어모델은 표현력 있는 게임 세계와 대화를 생성하지만, 제약 없는 생성은 불가능한 상태 전이, 퀘스트 정보 누설, 장기 캐릭터 지식 모순을 만들 수 있다. 본 연구는 확률적 제안과 권위 있는 상태 변경을 분리하는 엔진 독립 컨트롤러 TRACE-RPG를 제안한다. 타입 이벤트 로그, 지식 그래프, 퀘스트/공개 정책, 결정론적 검증기가 하드 커밋 게이트를 구성하며, 실패 후보에는 구조화된 반례를 제공해 제한 횟수만 수리한다. 시간 메모리와 불확실성 보정 감정 적응은 소프트 컨텍스트로만 작동하고 유효성을 덮어쓸 수 없다. 평가 프로토콜은 공개 가중치와 호스팅 모델 10개를 스크리닝하고 사전등록된 Pareto 규칙으로 3개를 승격한 뒤, 홀드아웃 세계와 퀘스트 모티프에서 세계 생성·NPC 대화·감정 적응의 6개 시스템 구성을 비교한다. 1차 결과, 혼합효과 분석, 검증기 의미 감사, 인간평가, 지연·에너지·재현성 규칙을 실행 전에 정의한다. 추적 가능한 확증 실험 전까지 결과는 의도적으로 비워 둔다(`TODO-RESULT`).

## 1. 서론

인터랙티브 게임에는 그럴듯한 문장 이상이 필요하다. 제안 행동은 현재 세계에서 실행 가능해야 하고, NPC는 알고 있으며 공개가 허용된 정보만 말해야 하며, 퀘스트는 계속 해결 가능해야 한다. 적응 기능도 단기 몰입을 위해 안전성을 희생해서는 안 된다. 프롬프팅과 검색은 조건화를 개선하지만 이를 불변식으로 만들지 못한다.

TRACE-RPG는 모델을 오류 가능한 제안기로 취급한다. 연구 기여는 모델에 독립적인 이벤트 소싱 커밋 프로토콜과, 형식 유효성·의미 누락·서사 품질·감정 적응을 분리해 평가하는 설계다.

계획된 기여는 다음과 같다.

1. 결정론적 재생이 가능한 타입화된 엔진 독립 상태/이벤트 계약,
2. 하드 검증과 제한된 반례 수리 프로토콜,
3. 출력이 비권위적인 시간 지식 및 감정 계층,
4. 유효성 조건부 다양성과 시스템 비용을 포함한 2단계 10개 모델 평가,
5. SCI/SCIE 저널 재현성을 위한 추적-주장 워크플로우.

등록된 검정 전에는 어떠한 기여도 실증적으로 우월하다고 표현하지 않는다.

## 2. 관련 연구와 공백

IVIE와 같은 뉴로-심볼릭 인터랙티브 픽션 연구는 점진적 검증 생성을 보였고[1], NPC 대화의 심볼릭 스캐폴딩 연구는 효과가 캐릭터 역할에 따라 달라질 수 있음을 보였다[2]. KNUDGE는 퀘스트와 엔티티 명세를 이용해 분기 대화를 조건화한다[3]. TextWorld는 텍스트 게임 상태의 실행 가능한 심볼릭 기준을 제공한다[4]. 그래프 검색[5], 시간 메모리[6], 생성적 시뮬레이션, RL 플레이스타일 에이전트[7], 게임 에이전트 벤치마크[8]는 각각 컨텍스트와 스트레스 테스트를 보완한다. 최근 게임 감정 평가는 보이는 단서가 잠재 몰입의 신뢰 가능한 추론을 뜻하지 않음을 경고한다[9].

| 선행 연구 축 | 실행 가능 상태 | 정책/공개 게이트 | 시간 근거 | 안전 제약 감정 적응 | 모델 간 시스템 비용 |
|---|---:|---:|---:|---:|---:|
| IVIE / TextWorld | 있음 | 부분 | 없음 | 없음 | 없음 |
| KNUDGE / 대화 스캐폴딩 | 부분 | 부분 | 없음 | 없음 | 없음 |
| G-Retriever / Mem0 | 게임 커밋 없음 | 없음 | 있음 | 없음 | 부분 |
| BALROG / RL 플레이스타일 | 환경 의존 | 없음 | 에피소드 의존 | 없음 | 부분 |
| TRACE-RPG 프로토콜 | 있음 | 인코딩 정책에 대해 있음 | 있음 | 게이트 조건부 있음 | 있음 |

이 표는 프로토콜 범위를 나타낼 뿐 측정된 우월성을 주장하지 않는다. 현재 참고문헌은 체계적 문헌고찰이 아닌 시작 집합이며, 투고 전 데이터베이스 검색식, 선별 수, DOI 정규화 서지정보, PRISMA형 제외 기록을 완성해야 한다.

남은 공백은 생성 방법의 부재가 아니다. 어떤 학습 구성요소도 권위 상태가 되지 않는 조건에서 세계 전이 안전성, NPC 정보 공개, 시간 메모리, 유효성 조건부 서사 다양성, 감정 적응, 실행 비용을 이질적인 모델에 걸쳐 함께 평가하는 감사 가능한 프로토콜이 부족하다.

## 3. 문제 정의

시점 \(t\)의 권위 상태를 다음과 같이 둔다.

\[
c_t=(G_t,q_t,m_t),
\]

여기서 \(G_t\)는 타입 세계/지식 그래프, \(q_t\)는 권위 있는 행동·퀘스트·공개 정책, \(m_t\)는 불변 이벤트 접두열이다. 학습된 감정 추정치 \(z_t\)는 명시적으로 비권위적이다. 제안기는 문맥 \(s_t=(c_t,z_t)\)를 관찰하고 다음 후보 이벤트를 표본화한다.

\[
a_t\sim p_\theta(a\mid c_t,z_t,R_k(c_t),h_t),
\]

\(R_k\)는 제한된 그래프 검색, \(h_t\)는 관찰 가능한 상호작용 기록이다. 결정론적 검증기는 술어 결과와 반례를 반환한다.

\[
V(c_t,a_t)=(v_{policy},v_{pre},v_{reach},v_{know},v_{disc},v_{quest},E_t).
\]

커밋 전이는 다음과 같다.

\[
c_{t+1}=\begin{cases}
T(c_t,a_t), & \bigwedge_i v_i=1,\\
c_t, & \text{그 외.}
\end{cases}
\]

첫 분기만 권위 상태를 변경한다. 수리는 \(j<K\)에서 이전 후보와 구조화된 오류 집합 \(E_t^{(j)}\)를 조건으로 \(a_t^{(j+1)}\)를 생성한다. 예산이 소진되면 검증되지 않은 생성을 쓰지 않고 결정론적 fallback으로 전환한다.

하드 유효성은 소프트 품질보다 사전식으로 우선한다. 유효 후보에 한해 다음 목적함수를 사용할 수 있다.

\[
J(a)=\lambda_nN(a)+\lambda_gQ_g(a)+\lambda_aA(a)-\lambda_cC(a),
\]

\(N\)은 서사 품질, \(Q_g\)는 근거성, \(A\)는 감정 곡선 효용, \(C\)는 지연·토큰·에너지 비용이다. 어떤 \(J\) 값도 무효 후보의 커밋을 허가하지 못한다.

## 4. 시스템 구조

컨트롤러는 다섯 계층으로 분리한다.

1. **근거와 상태:** 타입 그래프, 정책 상태, 불변 이벤트, 콘텐츠 주소 자산.
2. **검색:** 고정 컨텍스트 예산 내 현재 부분그래프와 근거 ID 추출.
3. **제안/형식화:** 텍스트 또는 멀티모달 모델이 스키마 제약 후보를 생성하되, 후보가 선언한 전제조건과 효과는 신뢰하지 않는다.
4. **검증/수리:** 독립 작성된 행동 정책 오라클이 요구조건 누락과 비허용 효과를 거부한 뒤 전제조건, 도달 가능성, NPC 지식, 공개, 퀘스트, 스키마 검사가 반례를 생성한다. 서사 텍스트-사실 의미 추출은 별도로 감사하는 학습 검사이며 형식 보장으로 주장하지 않는다.
5. **커밋/관찰:** 유효 이벤트만 커밋하고 엔진에 재생하며 정확한 리비전과 시간을 기록.

게임 엔진과 연구 런타임은 독립 빌드된다. 공유하는 가변 경계는 버전 브리지 이벤트뿐이므로 mock 엔진 또는 기록된 모델 응답을 이용해 추적을 재생할 수 있다.

## 5. 연구 질문과 가설

- **RQ1 / H1 (`C-RESULT-001`):** 전체 커밋 게이트는 승격 모델 전반에서 LLM-only와 retrieval-only보다 하드 위반 확률을 낮춘다.
- **RQ2 / H2 (`C-RESULT-003`):** 구조화 반례 수리는 동일 K의 맹목적 재시도보다 repair@K가 높고 생성 토큰이 적다.
- **RQ3 / H3 (`C-RESULT-004`):** 그래프 검색과 이벤트 소싱 시간 메모리는 유효성 조건부 서사 다양성을 보존하면서 장기 모순을 줄인다.
- **RQ4 / H4 (`C-RESULT-002`):** 감정 적응은 하드 유효성 비열등 한계를 위반하지 않고 목표 곡선 오차를 줄인다.
- **RQ5 / H5 (`C-RESULT-005`):** 컨트롤러 효과 방향은 모델 접근 방식과 규모 층에서 일관된다.

## 6. 실험 설계

### 6.1 모델과 단계

1단계는 `configs/model-matrix.yaml`의 정확한 10개 항목을 트랙별 30개 시나리오와 3회 반복으로 스크리닝한다. 이는 탐색 단계이며 최종 인과 주장을 만들지 않는다. 하드 유효성, 인간 품질, p95 지연, 비용의 동결된 Pareto 규칙으로 호스팅 대조군, 실행 가능한 공개 가중치 모델, 32GB 이하 프로필을 각각 승격한다.

2단계는 승격된 3개 모델을 트랙별 120개 시나리오와 5개 seed에서 LLM-only, RAG, KG, KG+policy, 전체 validator+repair, 전체+affect의 6개 시스템으로 평가한다. 검색, 정책, 검증, 수리, 메모리, 감정을 제거하는 절제 실험을 둔다. 세계, 퀘스트 템플릿, NPC 정체성, 관계 모티프 단위로 분할해 근접 중복 누출을 막는다.

### 6.2 시나리오

세계 생성은 판타지·미스터리·SF·교육 퍼즐, 대화는 힌트·흥정·기만·기억·관계 변화, 감정은 상승·해소·진동·관찰 불확실 곡선을 포함한다. 적대 사례는 도달 불가 객체, 모순 관찰, 조기 비밀 요청, 오래된 기억, 수리 불가능 코어, 오해를 유도하는 시각 감정 단서를 포함한다.

### 6.3 결과 지표

트랙별 1차 결과는 유효 에피소드율, 하드 대화 위반율, 하드 유효성 비열등 제약 아래 긴장 목표 RMSE다. 2차 결과는 후보당 위반, 해결 가능성, 금지 공개, repair@K, 시간 모순, KG precision/recall, 유효성 조건부 의미 다양성, 맹검 자연스러움, p50/p95 지연, 토큰, VRAM, 에너지, 검증기 위양성/위음성이다.

### 6.4 인간평가

파일럿에서 분산과 수행 시간을 추정하고, 임의의 참가자 수가 아니라 시뮬레이션/검정력 분석으로 확증 표본을 정한다. 제시 순서는 무작위·맹검이며 유효성이 일치한 출력만 품질 비교해 유창하지만 무효인 응답이 이기지 못하게 한다. 포함/제외, 주의력 검사, 동의, 보상, 인구통계, 평가자 신뢰도, 이상 사례를 보고한다. 합성 플레이어는 인간 연구를 대체하지 않는다.

### 6.5 통계 분석

분석 단위는 에피소드이며 후보 이벤트는 에피소드에 내포된 관측이지 독립 표본이 아니다. 각 `(model, scenario, seed)`를 대응 블록으로 두며, 5개 seed는 반복 확률 표본이므로 시나리오 수를 부풀리지 않는다. 이진 결과는 시스템, 승격 모델 층, 상호작용, seed 블록을 고정항으로 하고 세계와 시나리오 템플릿을 무작위 절편으로 둔 혼합효과 로지스틱 회귀를 사용한다. 서열 평가는 누적연결 혼합모형, 연속 결과는 변환 계층모형 또는 시나리오 군집 계층 bootstrap 구간을 사용한다.

확증 검정군은 결과를 보기 전에 동결한다. H1은 세계와 대화의 2개 1차 대조를 포함하고 양측 \(\alpha=.05\)에서 Holm 보정한다. H2와 H3는 각각 단일 양측 \(\alpha=.05\) 대조다. H4는 계층 게이트를 사용한다. 확증 결과 공개 전에 공학 허용치로 정한 절대 2%p 한계와 단측 \(\alpha=.025\)에서 유효성 비열등성을 먼저 통과해야 하며, 그 후 감정 RMSE 우월성을 양측 \(\alpha=.05\)에서 검정한다. RQ5의 시스템-모델 상호작용은 2차 추정량이다. API timeout, 파싱 실패, 수리 소진은 treatment-policy 추정량에 하드 무효로 남긴다. 응답 전 인프라 장애는 감사 사유와 함께 동일 seed로 한 번만 재실행하고 다시 실패하면 실패로 채점한다. 인간평가 결측은 단일 대치 없이 비율을 보고하고 MAR 및 delta-MNAR 민감도 분석을 수행하며, 에너지 텔레메트리 결측은 에너지 추정량에서만 제외한다. 원시 N, 군집·실패 수, 제외, 효과크기, 95% 구간, 진단을 보고한다.

## 7. 검증과 반증 루프

### 7.1 사실검증

모든 사실 문장은 `research/source-ledger.yaml`, 계획 결과는 `research/claim-ledger.yaml`에 연결한다. 허용되는 경우 1차 출처를 Scrapling으로 보존하며 접근 불가/robots 제한 페이지는 메타데이터만 남기고 검증 근거로 승격하지 않는다. deep-research 보고서와 브라우저 survey는 정확한 모델 ID, 출시 상태, 라이선스, 적용 범위에 합의해야 한다.

### 7.2 수식·논리 감사

독립 리뷰어가 상태 정의역, 수량자, 분모, 경계 조건, 도달 가능성 가정, 수리 종료, 인코딩된 건전성과 의미 완전성의 구분을 검토한다. 속성 테스트로 유효/무효 전이를 생성하고, 술어 제거 mutation test로 감사 민감도를 측정하며, 수동 라벨 사례로 검증기 false accept/reject를 추정한다.

### 7.3 실험설계 감사

확증 실행 전에 추정량-지표 정렬, 검정력, 무작위화, 누출, judge 의존, 다중성, 결측 처리, 중단 규칙, 하드웨어 비교 가능성, 사전등록 hash를 검토한다. 실패 시 결과 승격을 동결하고 수정 후 재실행한다.

## 9. 타당성 위협

형식 검사는 인코딩 술어에 대해 건전할 수 있으나 자연어 의미에는 불완전하다. snapshot 식별자에도 API가 변할 수 있다. 공개 가중치 모델은 서빙 스택과 양자화가 다르다. 시나리오 작성자가 벤치마크 고유 가정을 넣을 수 있다. 인간 평가는 문화·언어에 민감하다. 감정 라벨은 잡음이 크며 임상 상태로 해석해서는 안 된다. 텍스트/mock 환경 결과가 실시간 상용 게임으로 일반화되지 않을 수 있다. 측정 가능한 위협은 측정하고 나머지는 주장 범위를 제한한다.

## 10. 윤리와 아티팩트 정책

은밀한 감정 조작을 피하고 적응 제어를 공개하며, 텔레메트리는 최소화·가명화하고 삭제/보존 기간을 정한다. 인간 데이터 수집은 모집 전 해당 기관 심의와 동의를 요구한다. 공개 아티팩트에는 독점 게임 lore 대신 라이선스가 명확한 자체 제작 세계를 사용한다. 원본과 추적은 불변이며 파생 표는 생성 코드와 hash를 기록한다.

## 11. 결론

TRACE-RPG는 표현력 있는 학습 기반 생성이 양보 불가능한 심볼릭 커밋 경계 및 감사 가능한 적응과 공존할 수 있다는 도전적 가설을 검증 가능하게 만든다. 현재 기여는 반증 가능한 프로토콜과 실행 가능한 스캐폴드이지 긍정 결과가 아니다. 실증 결론은 등록되고 독립 검토된 파이프라인 완료 후에만 작성한다.
