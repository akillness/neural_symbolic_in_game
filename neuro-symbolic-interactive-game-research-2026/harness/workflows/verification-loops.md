# Verification loops

## Fact loop

`claim -> primary source -> local capture/hash -> independent cross-check -> status`. A claim without a direct source remains `thin-evidence` or `TODO`; inaccessible pages are never inferred from snippets alone.

## Math and logic loop

`formal definition -> dimensional/domain check -> boundary counterexample -> property test -> mutation test -> independent sign-off`. The reviewer must state whether a conclusion is a theorem of the encoding, a tested empirical regularity, or a design assumption.

## Experiment loop

`estimand -> manipulation -> metric -> power/simulation -> preregistration hash -> pilot -> leakage audit -> confirmatory run -> robustness`. Pilot data cannot silently join the confirmatory set.

## Result promotion loop

`trace IDs -> schema validation -> analysis script -> table checksum -> statistical review -> claim-ledger transition -> bilingual parity check`. A result is revoked if any upstream hash changes.

## Game bridge loop

`record -> replay in mock -> replay in engine -> state-hash equality -> latency budget -> fault injection`. A failed or timed-out model call must leave canonical state unchanged and invoke the safe policy.
