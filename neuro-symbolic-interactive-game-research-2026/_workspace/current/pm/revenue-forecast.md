# Resource and Study Rhythm Forecast

The harness calls this a revenue forecast; Cycle 1 uses a director-approved zero-economy override.
This document forecasts reproducibility cost rather than revenue.

| Beat | Unit | `[TARGET]` budget owner | Required telemetry |
|---|---|---|---|
| Authored headless episode | one unique scenario | programmer | build/content/state hashes, frame/request time |
| Structured model assignment | one model × arm × scenario × seed | experiment owner | token, latency, cost, failure class |
| Frozen VLM assignment | same plus image-pack hash | experiment owner | visual pack/version and modality |
| Independent annotation | one blinded item | future study owner | oracle version, rater pseudonym, timing, adjudication |

No forecast value is an observed cost. Actual provider and engine measurements must enter the
experiment record before paper use.
