# Hard Validity and Soft Adaptation

Hard validity is lexicographically prior to narrative, groundedness, affect, and cost objectives. A learned proposer, retrieved memory, visual observation, or affect score cannot authorize an invalid state transition.

SMT or deterministic rules prove only the predicates present in the encoding. Therefore TRACE-RPG pairs formal validation with a semantic audit that estimates false accepts and false rejects using independently labelled cases and predicate mutation tests.

Affect adaptation may optimize a target curve only among valid actions. High uncertainty, model failure, or timeout selects a deterministic safe policy. Tension, engagement, stress, arousal, and flow are not interchangeable labels.
